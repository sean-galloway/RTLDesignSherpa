# BUG-001: math_prefix_cell_gray.sv declares itself `math_prefix_cell`

**Priority:** P3. One line, but it is the only header mismatch in `rtl/math`.
**Status:** open 2026-09-26.

**The defect.** `rtl/math/math_prefix_cell_gray.sv` carries
`// Module: math_prefix_cell` -- the name of a DIFFERENT module in the same
directory. A reader or a tool taking the header at face value resolves to the
wrong file.

**Expected:** the header names the file it is in, `math_prefix_cell_gray`.

**Repro:**

```bash
grep -m1 '^// Module:' rtl/math/math_prefix_cell_gray.sv
# // Module: math_prefix_cell        <- wrong
```

**Second copy.** The same file exists under
`projects/asic-trials/timing_characterization/` with the same wrong header, so fix
both or the audit keeps reporting one.

**How it was found.** A repo-wide sweep of `// Module:` headers against filenames:
684 headers, 21 mismatched. 15 are rapids ([[rapids TASK-011]]), 4 are
`*_stub`/`verilator_xilinx_stubs` files where naming the stubbed primitive is
arguably deliberate, and these 2 are the only other real ones. `rtl/amba` has 197
headers with zero mismatches, `rtl/common` 48 with zero.

**Why it is worth a ticket.** In rapids this exact class caused every doc pass to
re-derive wrong module names and defeated four rounds of automated attribution.
Two files is cheap to fix before it spreads.
