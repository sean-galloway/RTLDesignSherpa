## CLOSED 2026-09-29 -- 16 sites in 11 files; the twelfth citation was a comment

Every `if (!<rst>)` directly under `ALWAYS_FF_RST` became
`` if (`RST_ASSERTED(<rst>)) ``: apb4_master_cg, apb4_slave_cg,
apb5_master_cg, apb5_slave_cg, apb5_slave_cdc_cg (its first block already
used the macro; the second did not), axis5_master_cg, axis5_slave_cg,
axil5_opt_slave (5 blocks), amba_clock_gate_ctrl, clock_divider (2),
dataint_checksum. The "raw block in clock_gate_ctrl.sv" the report names is
inside a usage-example comment (lines 140-141); the module's real block was
already on `RST_ASSERTED`. Nothing else in `rtl/` (outside OLD/) has the
pattern: the residue grep in [[reset-and-clocking]] prints nothing.
`pwm.sv` tests `sync_rst_n` inside the body -- a synchronous soft-reset
port, not the async reset -- and is correct as it stands.
