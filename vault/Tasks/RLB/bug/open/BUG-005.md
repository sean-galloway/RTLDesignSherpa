# BUG-005: the apb4_hpet example in PRD.md connects 9 ports that do not exist

**Priority:** P2
**Status:** open
**Owner:** RLB session
**Filed:** 2026-09-28

`PRD.md:422-443` instantiates `apb4_hpet` with nine port names the module does
not have. Anyone copying it gets nine PINMISSING/unknown-port errors at
elaboration.

| Example writes | Module actually declares |
|---|---|
| `.paddr` | `s_apb_PADDR` |
| `.psel` | `s_apb_PSEL` |
| `.penable` | `s_apb_PENABLE` |
| `.pwrite` | `s_apb_PWRITE` |
| `.pwdata` | `s_apb_PWDATA` |
| `.prdata` | `s_apb_PRDATA` |
| `.pready` | `s_apb_PREADY` |
| `.pslverr` | `s_apb_PSLVERR` |
| `.hpet_rst_n` | `hpet_resetn` |

Ports are `rtl/hpet/apb4_hpet.sv:197-227`. The example also omits `s_apb_PSTRB`
and `s_apb_PPROT`, which the module requires.

The PARAMETER block is correct -- `NUM_TIMERS`, `VENDOR_ID`, `REVISION_ID` and
`CDC_ENABLE` all exist (`:179-192`). Only the port connections are fabricated.

**Expected:** the example elaborates, or is marked as illustrative pseudo-code.

**Repro:** compare `PRD.md:428-442` against
`grep -nE '^\s*(input|output)' rtl/hpet/apb4_hpet.sv`.

## Why the gate did not catch it -- worth a tooling item

`bin/check_doc_examples.py` exists precisely to stop this ("No doc example
names a port the module lacks", a CI step), and it PASSES: 964 doc pages +
243 module pages, 7007 port-table rows, 0 fabricated. It never sees this file.
It walks `docs/markdown` plus `git ls-files '*CLAUDE.md'`; a component's
`PRD.md` and `README.md` are in neither set.

That is a RECURRENCE, and the script's own comment records the first one:
"Beside-code CLAUDE.md is in NO docs/ tree, so neither walk reached it --
rtl/amba/CLAUDE.md under this very gate until 2026-09-25 (amba BUG-001)."
The fix then was to widen the walk to `*CLAUDE.md`. `PRD.md` and `README.md`
are the same class of beside-code file and were not included.

Fixing this bug alone leaves the gate still blind to the next one. The scope
widening belongs on the tooling lane -- file it there rather than here, since
the mechanism is global and every component area shares it.
