parallelism (mode, max_run, beats; need >= 70% of beats):

>= ~134.

## What is known

- All six are perf-SHAPE assertions (command-stream run lengths, ceiling
  utilization), not data-integrity or bandwidth ceilings; the suite's
  integrity cells pass.
- They were almost all invisible until recently: the repo conftest's
  testcase anchor (tooling BUG-015) re-escaped `$`-suffixed testcase
  filters, so whole files ran ZERO cocotb tests and reported PASS (see
  [[BUG-025]] "why it went unseen" — same window). These cells' last REAL
  execution predates the common-plane MC-003-era work (entry-store
  rework, scheduler-plane v2, close-drain changes, 2026-10-13..16), so
  the shape deviation likely dates from that work, not from pumice
  proper.
- The 2026-10-17 MC-003 fix (episode/tRFC demand blocks in mc_bank_sched)
  is EXONERATED: pumice elaborates the FRFCFS core; the six fail
  identically with the pre-fix file.
