# BUG-014: the descriptor engine fetches any kicked address, in range or not

**Priority:** High -- the STREAM MAS (`ch02_blocks/05_descriptor_engine.md`)
lists "Address Range Validation: two configurable ranges for security"; the
ranges are what fences descriptor fetches from the rest of memory.
**Status:** CLOSED 2026-09-27 (closing note at the end); was OPEN 2026-09-27. Found by inspection while closing rapids BUG-006,
whose engine is the port of this one.

## Symptom (expected, not yet reproduced in a STREAM test)

A kick to an address outside both `cfg_addr0_*` / `cfg_addr1_*` ranges is
fetched and delivered like any other; no `descriptor_error`, no range error.
No STREAM test submits an out-of-range address -- the rapids
`test_address_range_validation` reject step is the reproduction to port.

## Mechanism

`rtl/fub/descriptor_engine.sv` computes `w_addr_range_valid` (line ~619) from
`r_axi_read_addr` and never consumes it; `w_validation_passed` is commented
out. Only the chained next pointer is range-checked (`w_chain_eligible`), so
the kicked address bypasses the check. Identical to rapids BUG-006.

## Fix recipe (from rapids BUG-006, `descriptor_engine_beats.sv`)

- `RD_ISSUE_ADDR`: step to `RD_ERROR` on `!w_addr_range_valid` before the
  AR handshake transition.
- Gate `ar_valid` with `w_addr_range_valid` in `RD_ISSUE_ADDR`; set the
  read-active flag on `ar_valid && ar_ready`, not `ar_ready` alone.
- Port the reject step into the STREAM descriptor engine TB, regenerate
  `formal/stream/descriptor_engine` flat, run the STREAM regression.

Applied 2026-09-27 (below).

## Closing note (2026-09-27)

Fix applied to `rtl/fub/descriptor_engine.sv` exactly as the recipe says.
New `address_range_reject` test type in `dv/tests/fub/test_descriptor_engine.py`
(`run_address_range_reject_test` in the TB): out-of-range kick raises
`descriptor_error`, issues no AR, delivers nothing; then a channel reset and an
in-range kick that must deliver. That recovery half found BUG-015 (the APB
in-progress flag survived channel reset), fixed alongside. `test_descriptor_engine`
17/17 at FULL; formal flat regenerated; full STREAM regression rerun.
