# BUG-005: sv2v regen: TWO stacked bugs, and `$display` was only the second
> **Was `TASK-087` until 2026-09-24.** Renamed when this area adopted per-lane ID sequences. Older references, commit messages and handbook notes use the old ID.

**Status:** CLOSED 2026-09-24  **Priority:** Medium

**Three things this entry originally got wrong.**

*1. "The prints are UNGUARDED -- no `ifdef`, no `translate_off`."* False. Both
blocks are guarded: `axi_write_engine.sv:909-934` by `// synopsys
translate_off`, and `:1001-1050` by `` `ifdef ENHANCED_DEBUG`` **plus**
translate_off. The distinction that matters is that **sv2v ignores
`translate_off`** -- it is a comment to sv2v -- while it **honours preprocessor
directives**. That is precisely why only the translate_off block reached the
flat and the five ENHANCED_DEBUG prints never did.

*2. `stream/axi_write_engine` marked "CAUSE CONFIRMED" for the `$display` issue.*
Reproducing it showed sv2v never gets that far:

```
sv2v: could not find package "monitor_arbiter_pkg"
  error, called at src/Convert/Package.hs:685:42
```

A **Makefile PKGS omission** -- `stream_imports.svh` imports
`monitor_common_pkg` AND `monitor_arbiter_pkg`, the Makefile passed only the
first. That is the "Convert/Package.hs package conversion bug" `FORMAL_TODO`
originally guessed at, and it is not an sv2v bug at all. The `AST_AUTOWIRE`
error the entry quoted came from `stream_core_flat.v:7007` -- a *yosys* error on
a *different* unit at a *later* stage -- generalised onto this one.

So there were **two stacked bugs**: the package omission first, and only behind
it the `$display`/`$time` AST_AUTOWIRE the entry described. The entry's cause
was real but unreachable.

*3. Scope was 4 units, not 2.* `datapath_wr_test` compiles the same source, and
RAPIDS `axi_write_engine_beats` inherited the identical block at the **same line
numbers** (909/923/1001) from the STREAM resync.
`retro_legacy_blocks/ioapic_deliv_merge` matched only in a comment.

**Fix -- Makefile only, no RTL mutation.** Add `monitor_arbiter_pkg` to
`axi_write_engine`'s PKGS, and give all four units a `.sv2v_prep` step that
strips `translate_off..translate_on` before sv2v. Simulation reads the original
source and still gets the prints. An isolation diff (same packages, strip vs
no-strip) removes exactly 18 lines -- the `r_stuck_counter` declaration and the
two autoblocks -- and adds 1, which is the same statement with its autoblock
renumbered 13->11. Zero functional change.
