# Book library

The owner's Kindle library (Hennessy & Patterson, Dally's interconnection
networks, the cache memory books, Chu's FPGA prototyping, the UVM primers,
Knuth, and ~70 more) is converted to one Markdown file per section with
provenance frontmatter, so an answer can rest on a cited chapter instead of
recall. It lives OUTSIDE this repo:

```
/mnt/data/github/calibre/books/
```

Pipeline, tagging and regeneration: `/mnt/data/github/calibre/README.md`.
Nothing under `books/` is committed anywhere (it is the books), so a fresh
clone of this repo does not bring it; the path above is a machine-local
resource on amdtrp.

## How to look something up

1. **`books/LIBRARY.md`** - every converted book with author, tags, chapter and
   section counts; then the same books grouped by tag. Pick by tag, not title.
2. **`books/CHAPTERS.md`** - every chapter title with its path. Route the
   question to a chapter, open that chapter's `index.md` for its sections.
3. **Read the section file** (`chNN-slug/N.M-slug.md`). It is 200-2,000 words
   with the figures as `../assets/*.png`. Several adjacent sections are cheap;
   a whole book is not (100k-250k tokens).
4. **`books/library.json`** when doing it programmatically: books, chapters,
   section paths and a `by_tag` map.

## Tags that matter here

Tags come from calibre (`organize/tags.tsv` in the pipeline repo) and appear in
`LIBRARY.md`. Two families are designed for this repo's questions:

| Need | Tag |
|---|---|
| ALU, multipliers, dividers, floating point, CORDIC | `area-arithmetic` |
| cache organisation, replacement, write policy | `area-cache`, `area-memory` |
| pipelines, hazards, ISA-level questions | `area-cpu-architecture`, `area-pipelining`, `area-isa` |
| NoC, routers, flow control, topologies | `area-noc`, `area-interconnect` |
| FSM encoding, logic synthesis | `area-fsm`, `area-logic-synthesis` |
| UVM, cocotb, ESL verification | `area-verification`, `area-uvm`, `area-cocotb` |
| FPGA-specific implementation | `area-fpga`, `area-digital-design` |
| DSP, SDR, error-correction codes | `area-dsp`, `area-sdr`, `area-coding-theory` |
| language of the examples | `lang-verilog`, `lang-systemverilog`, `lang-vhdl`, `lang-python`, `lang-cpp` |

Coarse categories (`hw-rtl`, `comp-arch`, `ml-ai`, `software`, ...) exist too.
`LOCKED` marks books whose DRM the toolchain cannot yet remove; they are in
calibre but have no Markdown tree, so they appear only at the end of
`LIBRARY.md`. `source-pdf` marks a tree built from a DRM-free PDF the owner
holds instead of the Kindle file; the text is the same but figures are page
renders and the odd page number survives inside code listings. Check the
edition in the title: a PDF may be an older edition than the Kindle copy.

## Citing

Every section file starts with frontmatter:

```yaml
source: "Computer Architecture: A Quantitative Approach"
chapter: "2 - Memory Hierarchy Design"
section: "2.3 - Ten Advanced Optimizations of Cache Performance"
```

Cite as *source, Ch section-number section-title*. Quote the book's claim,
then say what this repo does and why if it differs; the handbook note that
records the repo's rule is the authority on the rule, the book is the
authority on the general theory.

## Traps

- **Do not paste a book chapter into a handbook note or a spec.** Link the
  section path or cite it. The library is a private, format-shifted copy of
  purchased books; nothing from it is redistributed, and the repo's own notes
  must stay self-contained without it.
- **Figures are PNGs, equations are often images or garbled text.** A
  timing-diagram or derivation question is better answered from the image in
  `assets/` with a vision-capable model than from the text alone.
- **Tables can be column-aligned noise** after conversion. For a timing-parameter
  table, check the EPUB in `books/_epub/` or the PDF built with
  `bin/build_book_pdf.sh` before trusting the numbers.
- The trees are regenerated by the pipeline; a path is stable as long as the
  book's chapter titles are, so link to the chapter `index.md` rather than
  a deep section when the link must last.
