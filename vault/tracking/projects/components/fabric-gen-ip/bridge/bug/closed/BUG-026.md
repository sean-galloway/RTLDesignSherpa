# BUG-026: a slave narrower than the fabric address is decoded on its own addr_width

**Date:** 2026-10-23
**Priority:** P2
**Severity:** HIGH (misrouting, had it elaborated)
**Status:** CLOSED 2026-10-23 (fixed in `crossbar_generator._addr_decode_expr`; generator unit test)
**Owner:** unassigned
**Found by:** the Genesys 2 bridge stress model (`bridge_bs_mixed_b`, bridge TASK-019 phase 3e), whose APB slaves are 20 bits wide so that they see their window offset
**Affects:** any bridge with a slave port whose `addr_width` is below the widest port's. No configuration in the tree had one: `make regen` was byte-identical across all 733 generated files after the fix.

## Summary

The crossbar decodes every master's request on the fabric address, the
channel struct's `addr`, which is the package's `addr_width`: the widest port.
`_addr_decode_expr` took the width of its literals and of its full-span
shortcut from the slave's `addr_width` instead.

For an APB slave with `addr_width = 20` at `0x3000_0000`, that has two
effects:
- The emitted literal is `20'h30000000`, which Verilator rejects ("Too many
  digits for 20 bit number").
- Worse, had the literal fit, `max_addr` was `2^20 - 1`, so `end >= max_addr`
  held and the decode was emitted as `addr >= base` only. The slave would have
  claimed every address from its base up, overlapping every slave above it.

## Fix

`aw = max(addr_width over every master and slave)`, the package's address
width, for both the literals and the shortcut. A narrow slave still sees its
offset: its adapter and protocol shim drive `addr_width` bits.

## Verification

- `bin/tests/test_generator_pkg.py::test_narrow_slave_decode_uses_the_fabric_address_width`
  builds one AXI4 master and two 20-bit APB slaves (`0x3000_0000`,
  `0x4000_0000`). It requires no `20'h` literal and both 32-bit bounds per
  slave. It fails with the old line restored and passes with the fix.
  Generator unit tests: 224/224.
- `make regen`: 0 of 733 tracked generated files changed. No existing bridge
  is affected.
- Through the stress model: `bridge_bs_mixed_b` elaborates, and its APB slaves
  run in offset mode (TASK-019).
