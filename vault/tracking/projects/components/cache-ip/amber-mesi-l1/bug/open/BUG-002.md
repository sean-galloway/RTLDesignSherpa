# BUG-002: control FULL snoop soak 2126 — CRRESP IsShared set where oracle expects 0

**Priority:** P2
**Status:** open
**Owner:** TBD

Found 2026-10-12 by FULL grid v2 (leg amber_unit_macros). Deterministic:
same seed fails identically at HEAD (post l1_ rename), at 93ce944a2
(pre-rename, post deadlock-fix B), and at 255d8d9f5 (pre-Issue-A, pre-B,
pre-rename) — identical snoop index `full_sn[2126]`, same got/expected.
Pre-existing corner, exposed by seed luck; NOT caused by the 2026-10-11/12
TB fixes, the deadlock fix, or the l1_ rename. All directed snoop
scenarios pass; only the FullRandomLockstep soak trips it.

## Reproduction

```
cd projects/components/cache-ip/amber-mesi-l1/dv/tests
SEED=41099 REG_LEVEL=FULL python3 -m pytest -q \
  test_amber_control.py::test_l1_control_s128w4_full
```

Failure (1 mismatch in 1,144,313 checks / 10,066 txns / 2,524 snoops):

- `full_sn[2126] crresp: got 8 expected 0` — CRRESP bit 3 (IsShared in
  the 5-bit {WU, IS, PD, Err, DT} order) set where the model decode says
  the resolved reference state is not shared.

## Triage question

Reference-state resolution difference between `l1_control`'s grant-cycle
CRRESP decode and the TB's independent spec-copy decode (the formal
`ap_grant_crresp` property proves these agree at 16-set/2-way geometry —
the TB's Python decode is a separate implementation, worth diffing first),
vs a genuine tag-state tracking corner at 128-set/4-way that the small
geometry cannot reach. Note the formal safety proof does NOT cover
128-set/4-way.
