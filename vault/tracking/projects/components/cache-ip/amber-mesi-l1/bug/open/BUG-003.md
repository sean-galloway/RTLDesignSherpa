# BUG-003: tally bins all zero on some seeds ("MonBus observation path is silent") — seed-flaky, both levels, predates the 1wr swap

**Date:** 2026-10-25
**Priority:** P3
**Status:** open
**Owner:** TBD
**Where:** `projects/fpga-systems/Genesys2/cache-ip/amber/dv/tests/test_amber_pair_harness_axil.py` (`smoke_test` tally-bin assertion); the path under suspicion is `rtl/amber_pair_harness.sv` (monlite → arbiter → group → tally record ingest)
**Found by:** the monbus_axil4_group_1wr harness sweep, 2026-10-25

## What

`test_amber_pair_harness_axil[gate|func]` fails on some seeds with

```
AssertionError: tally bins all zero: MonBus observation path is silent
```

Three runs, three seeds, three failures, at EITHER level: gate (SEED=24983,
SEED=12478), func (SEED=83362). The same seed fails identically at
8854596d7 (before the 2026-10-25 stream/rapids 1wr commits) and with the
harness on `monbus_axil4_group_1wr`, so this is not the group swap: it is a
pre-existing marginal path. Sibling seeds pass at both levels, so roughly
every other seed is red. 2026-10-25 closing rerun for TASK-001: gate
SEED=74560 fails with the identical assertion (deterministic on the seed;
unpinned rerun passes), func levels green.

## Why it matters

A seed-flaky "observation silent" reads as a monitor regression whenever
anything in the monitor path changes, and every amber gate run is a coin
flip.

## Suspects (not yet root-caused)

- The BUG-004 territory: the group flushes its write path on
  `cfg_flush_watermark` (48 beats = 16 records) or a 1024-cycle timeout. A
  seed whose 200-injector smoke run produces fewer profiled events than a
  flush trigger, read before the timeout lands, shows all-zero bins.
- The tally legal-set profile keys on drop reports (the "health bin"); a
  seed with no drops and no profiled completions counts nothing.

cd projects/fpga-systems/Genesys2/cache-ip/amber/dv/tests
