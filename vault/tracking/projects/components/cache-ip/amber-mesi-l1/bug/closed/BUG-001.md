# BUG-001: miss_fill FULL soak txn 6040 — DUT serves hit where oracle expects miss + dirty-victim drain + fill

**Priority:** P2
**Status:** closed 2026-10-27 — TB model bug, same root cause as BUG-002
(stale {tag, I} corpse eviction retiring a live duplicate line); DUT was
correct.

Found 2026-10-12 by FULL grid v2 (leg amber_unit_macros). Deterministic:
same seed fails identically at HEAD (post l1_ rename), at 93ce944a2
(pre-rename, post deadlock-fix B), and at 255d8d9f5 (pre-Issue-A, pre-B,
pre-rename) — identical transaction index and check failures every time.

## Root cause

Same defect as BUG-002, one testbench-model bug in
`AmberControlTB._score_slice` eviction accounting (the miss_fill macro TB
subclasses it): a snoop invalidate leaves a dead {tag, I} corpse slot; when
a later miss evicted that slot, the accounting retired the line named by
the corpse's stale tag — clobbering the LIVE copy of the same line sitting
in another way. At `full[6040]` the corrupted model believed the line
absent and predicted miss + dirty-victim drain + fill; the DUT truthfully
served a hit from the live copy, so no victim/fill/replay machinery ran.

## Why the failure vanished at HEAD before the fix

2594d73bb (ACE conformance #106, 2026-10-12 21:19) changed RTL fill classes
and TB behaviour, shifting the soak's RNG stream — the seed stopped
exercising the corner, masking the bug. Proven by a worktree experiment:
at 7a3fe3000 (last pre-#106 commit), seed 81795 reproduces the filed
failure bit-identically (`full[6040]`, rsp data
1710588546579113756 vs 17601867675199592480); applying ONLY the eviction
guard there turns the run green (0 mismatches in 1,129,112 checks, same
stimulus). So the corner was never fixed by 2594d73bb — it was hidden, and
the guard is the true fix for both bugs.

## Fix / verification

See BUG-002 for the fix (pre-write victim-slot validity guard in
`_score_slice`, `_replay_models`, and `AmberMonliteTB`). Verification here:
the worktree proof above, plus at HEAD the miss_fill FULL grid (s128w4 and
s016w2, pinned and extra seeds incl. 81795) all green.
