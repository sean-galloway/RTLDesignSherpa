# BUG-007: the Genesys2 amber pair harness decodes 64 B of its 4 KB harness_csr window -- every offset aliases onto five registers

**Priority:** P3 (board-harness defect; latent on amber, whose host only
touches 0x000..0x010).
**Status:** CLOSED 2026-11-26 -- the decode covers the whole window.
**Owner:** TBD
**Where:** `projects/fpga-systems/Genesys2/cache-ip/amber/rtl/amber_pair_harness.sv`,
the harness_csr read mux and CTRL write decode. Same code as jet BUG-007,
where it surfaced.

## What was wrong

The read mux switched on `r_araddr[5:2]` and the CTRL write on
`r_awaddr[5:2]`, so every offset of the 4 KB window aliased modulo 0x40 onto
CTRL / STATUS / CYCLE_LO / CYCLE_HI / FABRIC_DBG. On jet, a host sequence
for the reference rig read 0x050 as "IO port present" and wrote CTRL
through 0x040 (jet BUG-007).

## Expected

An unmapped offset reads `0xDEADBEEF`; a write to one is dropped.

## The fix

Decode `addr[11:2]` (10-bit HCSR_* word indices), as on jet.
