# BUG-007: the Genesys2 jet pair harness decodes 64 B of its 4 KB harness_csr window -- every offset aliases onto five registers

**Priority:** P3 (board-harness defect; no cache logic involved, but a
host sequence misreads the rig and its writes land in CTRL).
**Status:** CLOSED 2026-11-26 -- the decode covers the whole window.
**Owner:** TBD
**Where:** `projects/fpga-systems/Genesys2/cache-ip/jet/rtl/jet_pair_harness.sv`,
the `jet_pair_harness_csr` read mux and CTRL write decode. amber's harness
has the same code (amber BUG-007).

## What was wrong

`harness_csr` is a 4 KB window (`docs/address_map.md`), but the read mux
switched on `r_araddr[5:2]` and the CTRL write on `r_awaddr[5:2]`. Every
offset aliased modulo 0x40 onto CTRL / STATUS / CYCLE_LO / CYCLE_HI /
FABRIC_DBG; only 0x14..0x3C read the `0xDEADBEEF` default.

The jet host package is shared with the reference rig, whose harness has
the onyx IO doorbell at 0x040..0x058. Run on the jet rig, `io_present()`
read IO_STATUS (0x050), got FABRIC_DBG (`{28'b0, dbg}`, bit 31 = 0) and
concluded an IO port exists; the sequence's writes to IO_ADDR (0x040) then
landed in CTRL (tally clear / freeze bits). The io sequence documents that
it "skips itself where IO_STATUS.absent reads 1"; on jet it could not.

## Expected

An unmapped offset reads `0xDEADBEEF` and a write to it is dropped, so
IO_STATUS.absent reads 1 on the jet rig and io skips itself.

## The fix

Decode `addr[11:2]` (the HCSR_* constants are 10-bit word indices).

## Verification

- `aperture_probe_test` now writes 0x040 and checks CTRL is unchanged, and
  reads 0x040, 0x050, 0x110 and 0xFFC expecting `0xDEADBEEF`. Before the
  fix it failed with exactly the alias ("write to unmapped 0x040 reached
  CTRL: 0x00000006; ... 0x050 read 0x00000000"); after it, the jet
  Genesys2 harness suite passes 6/6 from clean.
- Board (bitstream WNS +0.121 ns, 0 critical warnings): init, smoke PASS;
  io reports "no IO port in this selection (IO_STATUS.absent): skipped";
  bin 19 two-cache sweep 55/55 done, no error flags, every CRC equal to
  bin 17; single-cache sweep every CRC equal to the same-history run
  before the fix.
