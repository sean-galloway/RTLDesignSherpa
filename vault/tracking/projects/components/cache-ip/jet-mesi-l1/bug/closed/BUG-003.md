# BUG-003: jet_pair_fabric loses the buffer-free clear when a trailing absorption completes during the peer's replay -- the direction is never granted again (rig hang)

**Date:** 2026-11-09
**Priority:** P1
**Status:** closed 2026-11-09 -- fix committed with jet TASK-003 step 1; clean jet FULL 149/149 (first green FULL since v3), jet-g2 gate 2/2, Genesys2 bin 14 swept identical.
**Owner:** jet

## Symptom

`test_jet_pair_rig_s128w4l64b64_m16v1_fifo_mon_full`, `SEED=54355`: the rig
hangs at cycle 86,393 (reproduces deterministically with the seed). The hang
dump: core 0 holds one entry (line 0x558) with its fill queued and undone,
`m0_arvalid=1 / arready=0` forever; fabric `fstate 0 (F_IDLE) pend 01 buf 01
absp 00 grant_q 1 pend_cnt0 1`, no snoop in flight. Core 1 idle. Found by the
first FULL-level run of the pushed review RTL; the cell had never built before
(BUG-002).

The same fabric is the Genesys2 pair rig's coherence fabric, so this is a
board hang waiting for its timing.

## Cause

`jet_pair_fabric.sv`, the buffer-free rule. A data-carrying snoop response
fills `line_buf_q[grant_q]` and sets `buf_vld_q[grant_q]`; with PassDirty the
line is also absorbed to memory by the write port after the transaction, and
the buffer is freed either at `F_DONE` (no absorption pending) or when the
absorption's BVALID lands. That second clear was guarded by
`state_q != F_REPLAY_R`, unqualified by owner. When the BVALID of direction
0's absorption lands while the fabric is replaying direction 1's buffer
(`F_REPLAY_R`, `grant_q = 1`), the clear is skipped, `abs_pend_vld_q[0]`
drops on the same BVALID, and the later `F_DONE` clears only `grant_q`'s
buffer. `buf_vld_q[0]` stays set forever; `g_take[0] = pend_cnt != 0 &&
!buf_vld_q[0]` is then false forever and direction 0 is never granted: the
dump's `buf 01 / absp 00 / grant_q 1 / pend_cnt0 1`.

## Fix

Qualify the replay guard by owner, as the `F_REPLAY_AR` term already was:

    && !(state_q == F_REPLAY_R  && 2'(grant_q) == w_owner_q)
    && !(state_q == F_REPLAY_AR && 2'(grant_q) == w_owner_q)

The guard still protects the buffer being replayed from; the other
direction's buffer is freed when its absorption completes.
