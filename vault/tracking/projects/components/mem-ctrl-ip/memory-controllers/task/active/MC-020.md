## What

Find a form that lands the single-bank row hop on the odd CK without
re-entering the cone MC-014 cut:

- a registered idle-slot row fire: the lane's held pick fires into the odd
  CK of a main slot that was empty the cycle BEFORE (a register, not the live
  main valid), accepting one cycle of staleness;
- or the main select taking a row command for its own bank when that bank's
  column is timer-blocked by exactly the hop (the ACT after an RDA), so the
  ACT goes on phase 0 and the RD lands one MC cycle earlier.

Price each in the model first (`granite_sku_controller.cpp`: a `lane_idle`
knob is a ten-line change; `char_model.py --config` it against the SKU on
the `every` suite), then the RTL form, `TEST_DUAL` both ways, formal, the
no-knob sys100 build under the 0.2 ns budget.

## Done when

The model variant reproduces the +5 .. +15 on `col_major`, the RTL form gives
it in sim without moving another family outside the run-to-run band, and the
sys100 build closes with WNS >= 0 under the budget -- or the task is closed as
a recorded negative with the timing number that says why, as MC-014 recorded
the alone-firing lane.

## Step 1 landed (2026-11-21): the slot was not the tax

the close-page presets +35 .. +50 percent (tRRD 2 -> 1 doubles the ACT rate
