## What

Find a form that lands the single-bank row hop on the odd CK without
re-entering the cone MC-014 cut:

- a registered idle-slot row fire: the lane's held pick fires into the odd
  CK of a main slot that was empty the cycle BEFORE (a register, not the live
  main valid), accepting one cycle of staleness;
- or the main select taking a row command for its own bank when that bank's
  column is timer-blocked by exactly the hop (the ACT after an RDA), so the
  ACT goes on phase 0 and the RD lands one MC cycle earlier.

Price each in the model first (`granite_sku_controller.cpp`: a `lane_idle`
knob is a ten-line change; `char_model.py --config` it against the SKU on
the `every` suite), then the RTL form, `TEST_DUAL` both ways, formal, the
no-knob sys100 build under the 0.2 ns budget.

## Done when

The model variant reproduces the +5 .. +15 on `col_major`, the RTL form gives
it in sim without moving another family outside the run-to-run band, and the
sys100 build closes with WNS >= 0 under the budget -- or the task is closed as
a recorded negative with the timing number that says why, as MC-014 recorded
the alone-firing lane.

## Step 1 landed (2026-11-21): the slot was not the tax

`char_results/board_mc020_phase_exact_sku100_2026-11-21.md`. Both forms
above were priced in the model (`lane_idle` 1 live, 2 registered): 0.0 on
every `every` cell, `col_major` included -- on a one-bank chain the main slot
fires the ACT the slot its MC-cycle timer opens. What `slot1` measured was
the host's JEDEC derivation: a one-CK phase margin on every ns-derived
minimum, owed only while the DFI phases were unknown, and they are fixed
(columns on 0, row commands on 1). The phase-exact derivation gives tRC 6,
tWR 3, tWTR 3, tRRD 1, tRFC 13 (the rest unchanged); `sku_px` prices it as
col_major writes +10 / +7 / +5, reads 0; the proxy on one bank reproduces
+11 / +7 / +5, every family up, nothing down, every trace legal at CK
resolution (`bin/jedec_ck_check.py`, the trace now carrying the DFI phase);
the board on the step-5 bitstream: col_major 283 / 416 / 541 -> 311 / 446 /
565 writes with reads unmoved, the open-page SKU +0.1 .. +0.7 elsewhere, and
the close-page presets +35 .. +50 percent (tRRD 2 -> 1 doubles the ACT rate
of a bank-interleaved close-page stream), 0 mismatched beats in 81 cells.

The read side of the close-page chain did not move, because the RTL's
auto-precharge self-close sequences tRAS then the same tRP (5 + 2 = 7 MC)
where the CK-exact distance is 6: the one RTL item left, a `t_rp_ap` of its
own (per path -- the write path needs 2, the read path 1), priced by the
model at +12 .. +14 on every close-page read side and +13 .. +17 on the
bank_interleave bl4 cells. The model at the new counters is 51 / 6 against
the board for that reason and the mixed modes.

Open, the owner's: (1) the host default -- margin or phase-exact; (2) the
`t_rp_ap` RTL step. Also a tidy: the smoke derives its timings before the
DFI phases are programmed (ran tWR 4 under the flag; conservative).

## Decision 1 taken (2026-11-22): the phase-exact derivation is the default

`char_results/board_mc020_default_phase_exact_sku100_2026-11-22.md`. The
owner's condition was one soak at the new counters; the soak had to run the
SKU as the char measures it, not the reset state the bring-up soak soft-resets
into (lane off, `row_phase` 0, where the set is tWR 4), so a `soak` sequence
(`bin/seq_soak.py`) re-applies a `ControllerConfig` after every per-round reset,
and the derivation-order tidy came first (`SimpleTest` / `A7Leveling` derive
after `program_geometry`, from the device as programmed). 60 minutes, 2,493
rounds, 249 concurrent, 11 eye re-verifies, 21,944 MB, 0 dirty. Then the
default: `ddr2_char.jedec_timings_for` (phase-exact whenever the three phases
read back; `JEDEC_PHASE_EXACT=0` the margin), `TEST_PHASE_EXACT` default 1 on
the proxy, the model's SKU presets on `DDR2_GRANITE_SKU100_PX` (`sku_margin`
the old set). The board at the default: 81 cells, 99 runs, 0 mismatched, 66 of
77 cells within one percent of the 11-21 flagged run, the eleven moved all the
`bank_interleave` per-pass levels at the new ceiling (ISSUE-007, filed). The
model 51 / 6 with the same six: the `t_rp_ap` pair, one ISSUE-007 draw, the
three mixed cells (ISSUE-005, whose model preference inverted at the new
counters). Every board record before 2026-11-22 is the margin's.

Open, the owner's: (2) the `t_rp_ap` RTL step -- it pays only at the
phase-exact counters (under the margin the self-close's 5 + 2 was already the
margin tRC 7), which is why it waited for this decision.
