## The mechanism

The stimulus is deterministic (seeds are a hash of the scenario name, the
row-hit cells are fixed walks). What moves between runs is when GO lands
against the controller's tREFI countdown, which free-runs from init: the host
writes GO over UART. The proxy (fixed GO) shows the level is a function of
that phase (MC-023 item 4, ISSUE-007 2026-11-23).

## The design

- `mc_xddr2_refresh_ctrl.refi_reload_i` already reloads the countdown with
  the programmed tREFI (a DV knob, pumice's tests pulse it); granite carried it
  to `granite_core` and tied it 0 in `granite_top_geared`. Now a
  `granite_top_geared` test input (aclk), tied by the harness; a product ties
  it 0. Granite ties refresh postpone / pull-in off, so no refresh credit
  carries between passes.
- `chargen_regs.REF_ALIGN @ 0x618`: `en[0]` (reset 0), `offset[31:16]`.
- `char_engine_block.refi_reload_o`: armed, every launch (the GO pulse, any
  bit, already in mc_clk through the APB shim) loads the offset and the reload
  pulses at launch + offset + 1. `granite_char_macro` wires it to
  `granite_top_geared`; the pumice, scoria, LiteDRAM and fabric-benchmark
  consumers connect it empty (no reload input).
- Host: `DDR2CharDriver.set_ref_align(offset)`; `TEST_REF_ALIGN=<offset>` in
  `pumice_char.run_matrix` and the proxy (`test_granite_char_perf`), written
  only when set (an unconditional write would itself move GO on every
  unaligned run). The proxy checks every launch's reload distance and the
  countdown after it.

## Done when

- The proxy: with alignment on, a run with an extra register write before GO
  measures identically to one without (the MC-024 GO-shift case, `open_page`
  mixed at tREFI 781: 300 / 507 at reset against 280 / 282 with `dir_mode` 0
  written, unaligned); the offset moves the level as the tREFI phase did.
- Regressions at baseline (framework, granite, pumice, scoria, the
  consumers that connect the pin empty).
- The sys100 SKU bitstream closes under the 0.2 ns budget.
- The board: `windows` and `every` repeated at one offset are identical run
  to run (ISSUE-007's levels and the mixed modes fixed per offset), and an
  offset sweep reproduces the spread the free-running runs drew.
