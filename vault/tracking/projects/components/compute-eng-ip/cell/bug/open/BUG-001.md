**Priority:** P3
**Status:** open -- 2026-11-26
**Owner:** sean galloway

## Repro

```
cd projects/components/compute-eng-ip/cell/dv/tests

```


Every test has gate, func and full levels (test-patterns); the full cell runs
a larger seed set than func.
