## Built (2026-11-25, not committed yet)

`projects/components/riscv-ip/peregrine-rv32im/docs/simplified_rv32im/`,
"Memory Notes" branding after kestrel's `simplified_rv32i`, rev 0.1, one
DOCX/PDF pair (78 pages): 7 chapters, 19 sections.

1. Introduction: what peregrine adds over merlin; rung 3; conventions,
   including COD gap G8 (machine-mode names against COD §4.10's
   supervisor names).
2. Speculation: BTB/BHT and the 0-versus-2 lesson (Waveform 2.1); the
   install value (the 4-state bug, then `10` losing to predict-not-taken,
   `01` approved); the `BP_EN` A/B; the retire-stream check and the
   write-rule streams.
3. Precise traps: commit at MEM (Waveform 3.1); interrupts and the
   livelock behind ISSUE-001; `mret` and CSR read in EX / write in MEM.
4. The M unit: hold-in-EX against the scoreboard (Waveform 4.1); radix-2
   against `MUL_DSP` (CPI 9.16 / 3.83).
5. The memory hierarchy: split caches, the address map, `fence.i`;
   amber's hit time 4 -> 1 and the PRD §4.8 model; the stage-7 timing
   story and the 18.5 ns decision.
6. Verification: what each check sees and misses, the owner's formal
   scope decisions, the kinder-than-the-spec stub; the mutation passes.
7. Costs (cycles, area, clock, omissions) and the gyrfalcon teaser.

Figures: the four MAS graphviz diagrams, copied by `gen_figures.py`
(pipeline, predictor, traps, D side). Waveforms: the three PRD §5 asks
for (taken branch predicted and mispredicted, trap entry, M-unit stall),
generated by `gen_figures.py` with wavedrom-cli and inkscape from the
MAS cycle rules, not from a simulation trace. Every number traces to the
PRD or TASK-001 (one derived value: 2 x 18.5 ns = 37 ns per mispredict).

Build: `python3 gen_figures.py` (regenerates `assets/`; a no-op on
unchanged sources, checked), then `./generate_pdf.sh`, both from
`docs/simplified_rv32im/`. Checks: `check_doc_examples.py` 0 fabricated;
`bin/review/check_emoji.py` 0 emoji in 23 files; every relative link in
the book resolves.
