# STREAM on the Genesys 2 -- The FPGA System

**Version:** 1.0
**Date:** 2026-09-29
**Purpose:** What is on the bench and in the bitstream for the STREAM
characterization and monitor-validation system: the board, the harness that
surrounds the DUT, why one RTL source is built three ways (`mon`, `obs`,
`perf`) and what each build is for, and how a host program becomes a
measurement. The STREAM scatter-gather DMA is the device under test; its own
architecture lives in the STREAM HAS/MAS under
`projects/components/dma-ip/stream/docs/`.

> The measured results live in `reports/` (perf, compression, area, extended
> addressing) and the sign-off builds in `stable/` and `stable-obs/`. This
> book explains the apparatus. The older operator guide (`stream_char_guide`,
> v0.90) predates the Genesys 2 port and the three-build structure; this book
> supersedes its system description.

## Quick Reference

### Where things are

| Item | Path (under `projects/fpga-systems/Genesys2/stream/`) |
|------|------|
| Board top, harness, CSR, latency model | `rtl/stream_genesys2_top.sv`, `rtl/stream_harness.sv`, `rtl/harness_csr.sv`, `rtl/axi_response_delay.sv` |
| Generated bridges | `rtl/bridges/` (regenerated by `bin/regen_bridges.sh` as the PREBUILD step) |
| Harness CSR source | `regs/harness_csr.rdl` (PeakRDL; the Python register map is generated from it) |
| The three builds | `build-mon/`, `build-obs/`, `build-perf/` (variables only; the flow is `make/fpga_flow.mk`) |
| Shared host tools | `bin/` |
| Per-build host programs | `build-<x>/host/` |
| Sign-off copies | `stable/` (mon), `stable-obs/` (obs), each with a `MANIFEST.md` |
| Reports | `reports/perf`, `reports/compression`, `reports/area`, `reports/ext_addressing` |

### Identity

| Item | Value |
|------|-------|
| Board | Digilent Genesys 2, Kintex-7 XC7K325T-2 |
| Harness clock | 1200 MHz VCO / `CLKOUT0_DIVIDE`: 100, 80 or 60 MHz (the mon sign-off ran at 60) |
| Host link | UART 115200-8N1 on the board's FT232R; JTAG on its FT2232 |
| Builds | `mon` (8 ch, in-core monitors), `obs` (4 ch, observer taps), `perf` (8 ch, nothing but the datapath) |
