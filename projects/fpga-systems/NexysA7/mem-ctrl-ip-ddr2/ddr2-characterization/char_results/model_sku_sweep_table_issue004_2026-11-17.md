# Pattern x variant on the SKU model (base `granite_sku100`)

Each cell: write / read MB/s (two-direction rows add the union over the longer window) and, on the
second line, the delta of the headline number against the base column with the worst read wait in
MC cycles. Headline = the union for two-direction rows, else the larger direction.

- `granite_sku100`: THE SKU: GraniteSKU controller (bank-FIFO store, pick-core select, direction register, row lane, close-on-drain, one slot per MC cycle) at pool 16, BANK_CAP_MIXED 6, cap 255, hold-idle 8, on the host's MC-cycle timings (DDR2_GRANITE_SKU100)
- `sku_ideal16`: GenericDDR FRFCFS-RowHit at pool 16 on the SKU timing preset: the ideal with the SKU's counters
- `sku_pool8`: as granite_sku100 with pool 8
- `sku_pool24`: as granite_sku100 with pool 24
- `sku_pool32`: as granite_sku100 with pool 32
- `sku_cap0`: as granite_sku100 with BANK_CAP_MIXED off
- `sku_cap4`: as granite_sku100 with BANK_CAP_MIXED 4
- `sku_cap8`: as granite_sku100 with BANK_CAP_MIXED 8
- `sku_capburst`: as granite_sku100 with BANK_CAP_MIXED once per AXI burst, the burst's other beats exempt (the MC-018 form)
- `sku_lag0`: as granite_sku100 with a beat is a schedulable head the slot after its acceptance (the MC-018 form)
- `sku_lag2`: as granite_sku100 with admission lag 2 MC cycles
- `sku_lag6`: as granite_sku100 with admission lag 6 MC cycles
- `sku_reqfull`: as granite_sku100 with a request needs every timer, rank-level too (the MC-018 form: no cap flip to a turnaround-blocked column)
- `sku_batch64`: as granite_sku100 with DIR_BATCH_MAX 64
- `sku_batch128`: as granite_sku100 with DIR_BATCH_MAX 128
- `sku_batch0`: as granite_sku100 with no batch cap
- `sku_hold0`: as granite_sku100 with DIR_HOLD_IDLE off
- `sku_hold16`: as granite_sku100 with DIR_HOLD_IDLE 16
- `sku_noown`: as granite_sku100 with DIR_OWNS_ROWS off
- `sku_laneoff`: as granite_sku100 with the row lane off (DUAL_ISSUE 0)
- `sku_lanepre`: as granite_sku100 with the row lane carrying PRE only
- `sku_laneact`: as granite_sku100 with the row lane carrying ACT only
- `sku_noalt`: as granite_sku100 with no row / column alternation (columns first always)
- `sku_peek2`: as granite_sku100 with a two-entry peek (the two-head record as a real lookahead)
- `sku_peek16_pool32`: as granite_sku100 with pool 32 and a 16-deep row-hit peek past a conflicting head
- `sku_refburst8`: as granite_sku100 with eight refreshes per burst every 8 tREFI
- `sku_slot1`: as granite_sku100 with a command slot every CK (the one-slot-per-MC-cycle cost; the lane is then moot)
- `sku_jedec`: as granite_sku100 with the JEDEC CK timings (DDR2_MT47H64M16_400_CL3) instead of the host's MC-cycle counters
