# Ramulator 2 DDR2 model beside the measured granite sku100_2026-11-09 and LiteDRAM hx100_2026-10-31 cells

Cells are write / read MB/s at the 100 MHz MC clock (DDR2-400 x16 peak 800 MB/s), bandwidth = bytes moved over the
cycles from the first beat in to the last response out, the board host's definition. Model columns are the
Ramulator GenericDDR controller (FR-FCFS) on the DDR2 class at the part's timings (DDR2_MT47H64M16_400_CL3):

- `closed32`: FR-FCFS, close after one column access (auto-precharge), 32-deep queues
- `open32`: FR-FCFS, open page, 32-deep read and write queues, AllBank refresh
- `open32_mc2`: as open32 with every timing constraint rounded up to 2 CK (MC-cycle granular, as the RTL counts)
- `open32_noref`: as open32 without refresh
- `open8`: as open32 with 8-deep queues (granite's seam depth)
