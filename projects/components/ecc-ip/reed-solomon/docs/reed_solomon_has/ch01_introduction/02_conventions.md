# Document Conventions

## Terminology

- **Symbol**: an m-bit field element. `SYMBOL_WIDTH` = m. All arithmetic is
  in GF(2^m).
- **Block**: n symbols on the coded side, k on the data side. The core
  delimits blocks with a `last` flag on the final symbol of each.
- **Beat**: one transfer on a valid/ready port; carries
  `SYMBOLS_PER_BEAT = DATA_WIDTH / SYMBOL_WIDTH` symbols.
- **Profile**: one fully-resolved parameter set -- m, t, n, k, first root,
  primitive polynomial, scrambler -- typically named after the standard it
  matches (chapter 6.3).
- **Core**: `rs_encoder_core` or `rs_decoder_core`, valid/ready at both ends.
- **Adapter**: the optional AXIS or AXI4 boundary around a core.

## Naming

Module and signal names follow the repository conventions
(`vault/handbook/design/`): `aclk` / `aresetn`, active-low asynchronous
reset through the `ALWAYS_FF_RST` / `RST_ASSERTED` macros, `r_` registers
and `w_` wires internally, valid/ready per the house contract. Parameters
are upper case. Generated files carry a "Generated by" banner and live in
`rtl/generated/`.

## Notation

- n, k, t, m as above; 2t = n - k parity symbols.
- alpha: the primitive element of GF(2^m) defined by the primitive
  polynomial p(x); b: the first root of the generator polynomial
  g(x) = (x + alpha^b)(x + alpha^(b+1)) ... (x + alpha^(b+2t-1)).
- Lambda(x): error-locator polynomial; Omega(x): error-evaluator polynomial;
  S_i: syndromes.
- Counts quoted "for the reference profile" mean RS(255,239), t = 8, m = 8,
  one symbol per beat, unless a table says otherwise.

## Decision markers

Where the PRD has decided something, this document states it as fact and
cites the decision (for example "PRD D11"). Where the PRD has not, the text
says **TBD** and names the decision; chapter 6.2 collects every TBD in one
table.
