# Document Conventions

## Terminology

- **Bit**: one binary digit of the code word. The data and code streams are
  bit-oriented; there is no symbol framing inside the BCH block.
- **Symbol**: an m-bit field element used internally for GF(2^m) arithmetic.
  `SYMBOL_WIDTH` = m. The syndrome and key-equation hardware work in symbols;
  the Chien search evaluates the locator at n bit positions.
- **Block**: n bits on the coded side, k bits on the data side. The core
  delimits blocks with a `last` flag on the final bit of each.
- **Beat**: one transfer on a valid/ready port; carries `BITS_PER_BEAT` bits
  of one codeword (PRD D9 TBD).
- **Profile**: one fully-resolved parameter set -- m, t, n, k, first root,
  primitive polynomial -- typically named after the standard it matches
  (chapter 6.3).
- **Core**: `bch_encoder_core` or `bch_decoder_core`, valid/ready at both ends.
- **Adapter**: the optional AXIS or AXI4 boundary around a core.

## Naming

Module and signal names follow the repository conventions
(`vault/handbook/design/`): `aclk` / `aresetn`, active-low reset through the
`ALWAYS_FF_RST` / `RST_ASSERTED` macros, `r_` registers and `w_` wires
internally, valid/ready per the house contract. Parameters are upper case.
Generated files carry a "Generated by" banner and live in `rtl/generated/`.

## Notation

- n, k, t, m as above; n - k parity bits. The designed minimum distance is
  2t + 1.
- alpha: the primitive element of GF(2^m) defined by the primitive
  polynomial p(x); b: the first root of the generator polynomial
  g(x) = lcm{ minimal polynomials of alpha^b ... alpha^(b+2t-1) } over GF(2).
- Lambda(x): error-locator polynomial; S_i: syndromes.
- Counts quoted "for the reference profile" mean the CCSDS (63,56) profile,
  t = 1, m = 6, one bit per beat, unless a table says otherwise.

## Decision markers

Where the PRD has decided something, this document states it as fact and
cites the decision (for example "PRD D7"). Where the PRD has not, the text
says **TBD** and names the decision; chapter 6.2 collects every TBD in one
table.
