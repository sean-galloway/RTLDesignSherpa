# Acronyms

| Term | Meaning |
| --- | --- |
| CA | Command/Address bus (used by LPDDR2) |
| CS | Chip select |
| CKE | Clock enable |
| DFI | DDR PHY Interface |
| DDR | Double data rate SDRAM (generic) |
| DNV | Data not valid |
| DRAM | Dynamic random-access memory |
| MC | Memory controller |
| MRW | Mode register write (LPDDR2) |
| MRR | Mode register read (LPDDR2) |
| ODT | On-die termination |
| PHY | Physical interface (pads, clocks, delay lines) |
| RAS/CAS/WE | Row/column/write strobe signals |
| RD/WR | Read/write commands |
| REF | Refresh command |
| PRE | Precharge command |
| ACT | Activate command |
: Acronyms used in this book

**Source:** DFI Specification v2.1.1 Glossary (Section 6.0)
