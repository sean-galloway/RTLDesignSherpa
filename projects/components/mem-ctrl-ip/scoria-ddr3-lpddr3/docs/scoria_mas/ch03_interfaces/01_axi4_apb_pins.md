# AXI4 Slave and APB CSR at Pin Level

The host-side boundary of `scoria_top` is the family-standard AXI4 slave plus the PeakRDL register cpuif. Both are inherited from pumice unchanged at the protocol level; the widths below are the scoria design point. The AXI4-layer logic is described block-by-block in [AXI4 Layer](../ch02_blocks/01_axi4_layer.md); this page names the pins that cross the top-level shell.

## Clocks and resets

| Pin | Dir | Width | Source / sink | Notes |
|---|---|---|---|---|
| `aclk` | in | 1 | external | controller clock; AXI + scheduler + CAMs |
| `aresetn` | in | 1 | external | controller reset, active low |
| `dfi_clk` | in | 1 | external | PHY DFI clock |
| `dfi_rstn` | in | 1 | external | PHY reset, active low |
| `init_done_o` | out | 1 | `scoria_top` | initialization complete (also echoed into `STATUS`) |

## PeakRDL register cpuif

The CSR block is generated by PeakRDL and exposed through a simple req/ack cpuif. Doctrine 3 of the family docs applies unchanged: the host side is AXI4 + APB, and the register map comes from RDL. The APB-to-cpuif CDC is an integration concern, not a `scoria_top` port; see the HAS integration note. The generated register reference is `regs/generated/docs/scoria_csr.md`.

| Pin | Dir | Width | Description |
|---|---|---|---|
| `s_cpuif_req` | in | 1 | request valid |
| `s_cpuif_req_is_wr` | in | 1 | 1 = write, 0 = read |
| `s_cpuif_addr` | in | 12 | byte address into the 4 KB map |
| `s_cpuif_wr_data` | in | 32 | write data |
| `s_cpuif_wr_biten` | in | 32 | per-byte write enables |
| `s_cpuif_req_stall_wr` | out | 1 | write request stalled |
| `s_cpuif_req_stall_rd` | out | 1 | read request stalled |
| `s_cpuif_rd_ack` | out | 1 | read acknowledge |
| `s_cpuif_rd_err` | out | 1 | read error |
| `s_cpuif_rd_data` | out | 32 | read data |
| `s_cpuif_wr_ack` | out | 1 | write acknowledge |
| `s_cpuif_wr_err` | out | 1 | write error |

## Register liveness classes

| Class | Registers | Notes |
|---|---|---|
| Continuously live | all core timings (`tRCD`, `tRP`, `tRAS`, `tRC`, `tWR`, `tRTP`, `tRTW`, `tRRD`, `tFAW`, `tWTR`, `tCCD`, `tRFC`, `tREFI`), `SCHED_POLICY`, `SCHED_WR_WM`, `PAGE_POLICY_CFG`, `PAGE_TIMEOUT_CFG`, `REF_CTRL`, `ZQ_CFG`, `ADDR_MAP` | Sampled every cycle by the core. Safe to change only when the effect is intended. |
| Live but should not change mid-traffic | `DFI_PHASE.bl`, `DFI_PHASE.gear_ratio`, `PHY_TIMING.memtype` | No protection; wrong values are bad config, not synthesis errors. |
| Consumed at init | `INIT_TIMING0/1/2`, `MR0..MR3.VAL` | New values take effect only when `CTRL.init_force_restart` replays the MRS chain. |
| Read-only status/telemetry | `STATUS`, `WRLVL_STATUS*`, `ZQ_STATUS`, `ZQ_OBS_INTERVAL`, `PAGE_STATS_*`, `SCHED_STATS_*`, `REF_STATS_*`, `STALL_*`, `OBS_ROW_HIT[*]`, `ID`, `BUILD` | Driven by hardware. |

## The N+1 timing convention

Every JEDEC timing field in the core-timing registers is a count of MC cycles to block, so a value programmed as `N` is enforced as `N+1` cycles of command spacing. The counter is loaded with `N` on the event and the gate opens the cycle after it would reach zero. This is stated explicitly in `TIMINGS_RC_RCD_RP_RAS` and is measured tight in `formal/scoria/bank_timer` and `formal/scoria/global_timers` (`a_*_bound_n1`). Program the JEDEC value from the part datasheet; do not subtract one to compensate.

The generated register reference with full field descriptions is `regs/generated/docs/scoria_csr.md`.
