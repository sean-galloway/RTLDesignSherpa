# Acronyms

| Term | Meaning |
| --- | --- |
| ACT | Activate command |
| BG | Bank group (DDR4) |
| CA | Command/Address bus |
| CRC | Cyclic redundancy check |
| CS | Chip select |
| DB | Data buffer (LRDIMM) |
| DBI | Data bus inversion |
| DFI | DDR PHY Interface |
| DNV | Data not valid |
| DQ | Data pin group (data + mask/DBI + strobe) |
| DQS | Data strobe |
| FGR | Fine granularity refresh |
| LPDDR | Low-power DDR |
| MC | Memory controller |
| MPC | Multi-purpose command (LPDDR4) |
| MR | Mode register |
| MRR | Mode register read |
| MRS | Mode register set |
| MPR | Multi-purpose register (DDR4) |
| ODT | On-die termination |
| PHY | Physical layer (the DRAM interface block) |
| PRE | Precharge command |
| RD | Read command |
| REF | Refresh command |
| SDR | Single data rate |
| SR | Self-refresh |
| WR | Write command |
| 3DS | Three-dimensional stacked DRAM |

: Acronyms used in this book

**Source:** DFI Specification v4.0 section 2.2
