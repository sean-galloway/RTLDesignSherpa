# Training, DB Training, PHY Master, Geardown and LPDDR4 Channels

DFI 4.0 adds several specialized interfaces beyond the core control/data path. This chapter
covers training (gate, read data eye, write leveling, CA, write DQ), DB training for LRDIMM, the
PHY master protocol, geardown mode, and LPDDR4 channel configuration.

## DFI training interface

DFI 4.0 supports four training operations: gate training, read data eye training, write leveling, and
CA training. Write DQ training is new in 4.0. Training can run in DFI Training Mode (MC/PHY
handshake over DFI) or PHY Independent Mode (PHY runs training on its own). The andesite
design point uses DFI Training Mode.

### Training signals

| Signal | Width | Default | Direction | What it does |
| --- | --- | --- | --- | --- |
| `dfi_calvl_ca_sel` | Defined by `tcalvl_ca_sel` | 0x0 | MC -> PHY | CA foreground pattern strobe; indicates when foreground pattern should be transmitted PHY-to-DRAM. |
| `dfi_calvl_capture` | DFI CA Training MC I/F Width | 0x0 | MC -> PHY | One-DFI-clock pulse initiating capture of CA bus value from DQ bus. |
| `dfi_calvl_data` | 7 bits per slice | - | MC -> PHY | CA VREF training value to transfer to DRAM, per slice. |
| `dfi_calvl_done` | 1 bit | 0x0 | MC -> PHY | MC has finished iterating VREF values; PHY responds with `dfi_calvl_resp`. |
| `dfi_calvl_en` | Per slice | 0x0 | MC -> PHY | CA training logic enable per slice; assertion initiates CA training and acknowledges `dfi_calvl_req`. |
| `dfi_calvl_req` | Per slice | 0x0 | PHY -> MC | PHY-initiated CA training request per slice. |
| `dfi_calvl_resp` | 2 bits | 0x0 | PHY -> MC | CA training response: `00` in-process, `01` LPDDR4 VREF sequence done / LPDDR3 reserved, `10` LPDDR3 change-segment / LPDDR4 reserved, `11` complete. |
| `dfi_calvl_result` | 1 bit | 0x0 | PHY -> MC | VREF comparison result: `1` = current value better than previous best. |
| `dfi_calvl_strobe` | Per slice | 0x0 | MC -> PHY | CA VREF training strobe per slice; each DFI clock of assertion generates one DQS pulse. |
| `dfi_lvl_pattern` | 4 bits x read-training width | 0x0 | MC -> PHY | Read-training pattern select. For DDR4/LPDDR2/3 defines pattern directly; for LPDDR4 indexes a programmed table. |
| `dfi_lvl_periodic` | Leveling width | 0x0 | MC -> PHY | Global training length: `0` = full/long, `1` = periodic/short. |
| `dfi_phy_calvl_cs` | DFI Physical Rank Width | inactive | PHY -> MC | CA training target chip select. |
| `dfi_phy_rdlvl_cs` | Rank x read-training width | inactive | PHY -> MC | Read data eye training target chip select. |
| `dfi_phy_rdlvl_gate_cs` | Rank x read-training width | inactive | PHY -> MC | Gate training target chip select. |
| `dfi_phy_wdqlvl_cs` | Rank x write-DQ width | inactive | PHY -> MC | Write DQ training target chip select. |
| `dfi_phy_wrlvl_cs` | Rank x write-leveling width | inactive | PHY -> MC | Write leveling target chip select. |
| `dfi_rdlvl_done` | Per slice | 0x0 | MC -> PHY | Read data eye training: MC finished iterating training values. |
| `dfi_rdlvl_en` | Per slice | 0x0 | MC -> PHY | Read data eye training enable per slice; acknowledges `dfi_rdlvl_req`. |
| `dfi_rdlvl_gate_en` | Per slice | 0x0 | MC -> PHY | Gate training enable per slice; acknowledges `dfi_rdlvl_gate_req`. |
| `dfi_rdlvl_gate_req` | Per slice | 0x0 | PHY -> MC | PHY-initiated gate training request per slice. |
| `dfi_rdlvl_req` | Per slice | 0x0 | PHY -> MC | PHY-initiated read data eye training request per slice. |
| `dfi_rdlvl_resp` | Read response width | 0x0 | PHY -> MC | Read training status: `00` in-process, `01` sequence done (data-eye only), `10` reserved, `11` complete. |
| `dfi_wdqlvl_done` | Per slice | 0x0 | MC -> PHY | Write DQ training: MC finished iterating VREF values. New in 4.0. |
| `dfi_wdqlvl_en` | Per slice | 0x0 | MC -> PHY | Write DQ training enable per slice. New in 4.0. |
| `dfi_wdqlvl_req` | Write-DQ width | 0x0 | PHY -> MC | PHY write DQ training request. New in 4.0. |
| `dfi_wdqlvl_resp` | Write-DQ response width | 0x0 | PHY -> MC | Write DQ training response. New in 4.0. |
| `dfi_wdqlvl_result` | 1 bit | 0x0 | PHY -> MC | Write DQ VREF comparison result. New in 4.0. |
| `dfi_wrlvl_en` | Per slice | 0x0 | MC -> PHY | Write leveling enable per slice; acknowledges `dfi_wrlvl_req`. |
| `dfi_wrlvl_req` | Write-leveling width | 0x0 | PHY -> MC | PHY write leveling request. |
| `dfi_wrlvl_resp` | Per slice | 0x0 | PHY -> MC | Write leveling response: `0` in-process/not active, `1` complete. |
| `dfi_wrlvl_strobe` | Per slice | 0x0 | MC -> PHY | Write leveling strobe per slice; assert count per request set by `syswrlvl_strobe_num`. |

: DFI training interface signals

### Training timing parameters

| Parameter | Description |
| --- | --- |
| `tcalvl_ca_sel` | Width generated by combining per-phase PHY inputs for `dfi_calvl_ca_sel`. |
| `tcalvl_capture` | DFI clocks after calibration command on `dfi_cs` before `dfi_calvl_capture` pulse. |
| `tcalvl_cc` | Min DFI clocks from one calibration command to the next. |
| `tcalvl_cs_ca` | PHY DFI clocks from `dfi_calvl_ca_sel` assertion to `dfi_cs`. |
| `tcalvl_data` | Min DFI PHY clocks `dfi_calvl_data` must be held for DRAM hold time. |
| `tcalvl_en` | Min DFI clocks from `dfi_calvl_en` assertion to `dfi_cke` de-assertion. |
| `tcalvl_max` | Max DFI clocks MC waits for `dfi_calvl_resp` after asserting `dfi_calvl_en`. |
| `tcalvl_resp` | Max DFI clocks from `dfi_calvl_req` to MC asserting `dfi_calvl_en`. |
| `tcalvl_strobe` | Min DFI PHY clocks from `dfi_calvl_data` to `dfi_calvl_strobe` for DRAM setup. |
| `trdlvl_en` | Min DFI clocks from `dfi_rdlvl_en`/`dfi_rdlvl_gate_en` to first read/MRR command. |
| `trdlvl_max` | Max DFI clocks MC waits for `dfi_rdlvl_resp` after setting read training enable. |
| `trdlvl_resp` | Max DFI clocks from read training request to MC asserting enable. |
| `trdlvl_rr` | Min DFI clocks between consecutive read-training read commands. |
| `twdqlvl_en` | Min DFI clocks from `dfi_wdqlvl_en` to first write command. |
| `twdqlvl_max` | Max DFI clocks MC waits for `dfi_wdqlvl_resp` after asserting `dfi_wdqlvl_en`. |
| `twdqlvl_resp` | Max DFI clocks from `dfi_wdqlvl_req` to MC asserting `dfi_wdqlvl_en`. |
| `twdqlvl_rw` | Min DFI clocks from last read to first write of next calibration commands. |
| `twdqlvl_ww` | Min DFI clocks between write commands during write DQ training. |
| `twrlvl_en` | Min DFI clocks from `dfi_wrlvl_en` to first `dfi_wrlvl_strobe`. |
| `twrlvl_max` | Max DFI clocks MC waits for `dfi_wrlvl_resp` after setting `dfi_wrlvl_en`. |
| `twrlvl_resp` | Max DFI clocks from `dfi_wrlvl_req` to MC asserting `dfi_wrlvl_en`. |
| `twrlvl_ww` | Min DFI clocks from one `dfi_wrlvl_strobe` to the next. |

: Training timing parameters

### Training programmable parameters

| Parameter | Description |
| --- | --- |
| `mcrdlvl_slice_group` / `phyrdlvl_slice_group` | Per-slice grouping of `dfi_rdlvl_en` bits. All-1 reproduces DFI 3.1 behavior; all-0 enables fully independent per-slice leveling. |
| `phycalvl_en` | `1` = DFI CA training enabled in PHY. |
| `phyrdlvl_en` / `phyrdlvl_gate_en` | PHY supports read data eye / gate training on DFI bus. |
| `phywrlvl_en` | PHY supports write leveling on DFI bus. |
| `phywdqlvl_bst` | Number of consecutive write bursts per write DQ training sequence. |
| `syswrlvl_strobe_num` | Minimum clocks `dfi_wrlvl_strobe` asserts per write leveling request. |

: Training programmable parameters

## DB training interface

The DB training interface supports DDR4 LRDIMM data-buffer-to-DRAM training in PHY
evaluation mode.

| Signal | Width | Default | Direction | What it does |
| --- | --- | --- | --- | --- |
| `dfi_db_train_en` | Per slice | 0x0 | MC -> PHY | Enables DB training mode: PHY transfers commands from MC and captures DQ inputs for return on response bus. |
| `dfi_db_train_resp` | Per slice x DQ per slice | 0x0 | PHY -> MC | DQ data returned to MC for evaluation during DB training. Word-suffixed `_wN`. |

: DB training interface signals

| Parameter | Description |
| --- | --- |
| `tphy_db_train_en` | PHY DFI clocks after `dfi_db_train_en` asserts until first training command can be issued. |
| `tphy_db_train_resp` | Max DFI clocks from PHY DQ input to `dfi_db_train_resp` output. |

: DB training timing parameters

## PHY master interface

The PHY master interface lets the PHY take temporary control of the DRAM bus. This is used for
PHY-initiated training or other maintenance that requires the PHY to drive commands directly.

| Signal | Width | Default | Direction | What it does |
| --- | --- | --- | --- | --- |
| `dfi_phymstr_ack` | 1 bit | 0x0 | MC -> PHY | PHY master acknowledge: MC has placed DRAM in a known state and PHY is master of the DRAM bus. |
| `dfi_phymstr_cs_state` | DFI Chip Select Width | 0x0 | PHY -> MC | Per-rank DRAM state when PHY becomes master: `0` = IDLE or self-refresh per `dfi_phymstr_state_sel`; `1` = MC may choose any supported state. |
| `dfi_phymstr_req` | 1 bit | 0x0 | PHY -> MC | PHY requests control of DFI/DRAM buses. |
| `dfi_phymstr_state_sel` | 1 bit | 0x0 | PHY -> MC | For CS with `dfi_phymstr_cs_state=0`: `0` = MC must place memory in IDLE, `1` = self-refresh. |
| `dfi_phymstr_type` | 2 bits | 0x0 | PHY -> MC | Selects one of four PHY master time classes (`tphymstr_type0`..`3`). |

: PHY master interface signals

| Parameter | Description |
| --- | --- |
| `tphymstr_resp` | Max DFI clocks from `dfi_phymstr_req` to `dfi_phymstr_ack`. |
| `tphymstr_rfsh` | Max DFI clocks PHY needs to forward a refresh command from MC to DRAM while master. |
| `tphymstr_type0`..`3` | Max cycles `dfi_phymstr_req` may stay asserted after ack for each type. |

: PHY master timing parameters

### Inactive chip selects

DFI 4.0 introduces `syscs_state`, a per-chip-select state: `0` = inactive (unpopulated,
uninitialized, powered off, DPD, MPSM), `1` = active. The PHY must not assert training chip-select
bits for inactive ranks. This lets a controller and PHY handle partially populated systems without
treating empty slots as errors.

## Geardown mode

Geardown mode is a DDR4 feature where the CA bus runs at half the memory clock rate. The MC
changes CA signals only every other DFI PHY clock, synchronized by the PHY.

| Signal | Width | Default | Direction | What it does |
| --- | --- | --- | --- | --- |
| `dfi_geardown_en` | 1 bit | 0x0 | MC -> PHY | When asserted, MC and PHY operate in DDR4 geardown mode. New in 4.0. |

: Geardown mode signal

| Parameter | Description |
| --- | --- |
| `tgeardown_delay` | Delay from `dfi_geardown_en` assertion until PHY is ready to receive commands. |

: Geardown timing parameter

## LPDDR4 channels

LPDDR4 supports two independent 16-bit channels or one combined 32-bit channel.

| Parameter | Description |
| --- | --- |
| `phychannel_en` | Which DFI channels are enabled in LPDDR4 combined mode: `01` = ch0, `10` = ch1, `11` = both. Independent mode requires both. |

: LPDDR4 channel programmable parameter
