# Full Timing Parameter Table

This table lists every DFI 4.0 timing parameter from the inventory, grouped by sub-interface.

| Parameter | Sub-interface | Defined by | Description |
| --- | --- | --- | --- |
| `tcmd_lat` | Control | MC | DFI PHY clocks from `dfi_cs` assertion until associated CA signals are driven (LPDDR4 CS-to-CA). |
| `tctrl_delay` | Control | PHY | DFI clocks from a control signal change to the change reaching the DRAM interface. |
| `tphy_crcmax_lat` | Write Data | System | Max DFI PHY clocks from `dfi_wrdata_en` (CRC word cycle) to associated CRC error on `dfi_alert_n`. |
| `tphy_crcmin_lat` | Write Data | System | Min DFI PHY clocks for the same CRC error path. |
| `tphy_wrcsgap` | Write Data | PHY | Min additional DFI PHY clocks between commands when changing target rank on `dfi_wrdata_cs`. |
| `tphy_wrcslat` | Write Data | PHY | DFI PHY clocks from write command to assertion of associated `dfi_wrdata_cs`. |
| `tphy_wrdata` | Write Data | PHY | DFI PHY clocks from `dfi_wrdata_en` assertion to write data driven on `dfi_wrdata`. |
| `tphy_wrlat` | Write Data | PHY | DFI PHY clocks from write command on control interface to `dfi_wrdata_en` assertion. |
| `twrdata_delay` | Write Data | System | DFI clocks from `dfi_wrdata_en` assertion to write data transfer completion on DRAM bus. |
| `tphy_rdcsgap` | Read Data | PHY | Min additional DFI PHY clocks between commands when changing target rank on `dfi_rddata_cs`. |
| `tphy_rdcslat` | Read Data | PHY | DFI PHY clocks from read command to assertion of associated `dfi_rddata_cs`. |
| `tphy_rdlat` | Read Data | PHY | Max DFI PHY clocks from `dfi_rddata_en` assertion to each corresponding `dfi_rddata_valid` bit. |
| `trddata_en` | Read Data | System | DFI PHY clocks from read command on DFI to `dfi_rddata_en` assertion. |
| `tctrlupd_interval` | Update | MC | Max DFI clocks the MC may wait between `dfi_ctrlupd_req` assertions. |
| `tctrlupd_max` | Update | MC | Max DFI clocks `dfi_ctrlupd_req` can be asserted. |
| `tctrlupd_min` | Update | MC | Min DFI clocks `dfi_ctrlupd_req` must be asserted. |
| `tphyupd_resp` | Update | PHY | Max DFI clocks from `dfi_phyupd_req` assertion to `dfi_phyupd_ack` assertion. |
| `tphyupd_type0` | Update | PHY | Max DFI clocks `dfi_phyupd_req` may stay asserted after ack for type 0. |
| `tphyupd_type1` | Update | PHY | Max DFI clocks for type 1. |
| `tphyupd_type2` | Update | PHY | Max DFI clocks for type 2. |
| `tphyupd_type3` | Update | PHY | Max DFI clocks for type 3. |
| `tdram_clk_disable` | Status | PHY | DFI clocks from `dfi_dram_clk_disable` assertion until DRAM clock holds low at PHY-DRAM boundary. |
| `tdram_clk_enable` | Status | PHY | DFI clocks from `dfi_dram_clk_disable` de-assertion to first valid DRAM clock rising edge. |
| `tinit_complete` | Status | PHY | Max DFI clocks from `dfi_init_start` de-assertion to `dfi_init_complete` re-assertion during frequency change. |
| `tinit_complete_min` | Status | PHY | Min DFI clocks before `dfi_init_complete` can be driven after a previous command/training event. |
| `tinit_start` | Status | MC | DFI clocks from `dfi_init_start` assertion until PHY must de-assert `dfi_init_complete` to accept frequency change. |
| `tinit_start_min` | Status | PHY | Min DFI clocks before `dfi_init_start` can be driven after a previous command/training event. |
| `tparin_lat` | Status | MC | DFI PHY clocks between DFI command assertion and associated `dfi_parity_in`. |
| `tphy_paritylat` | Status | PHY | Max DFI clocks between `dfi_parity_in` and associated `dfi_alert_n` return (min 0x4). |
| `terror_resp` | Error | PHY | Max DFI clocks from affected DFI bus transaction(s) to `dfi_error` assertion. |
| `tcalvl_ca_sel` | Training | PHY | In frequency-ratio systems, defines `dfi_calvl_ca_sel` width generated by combining per-phase PHY inputs. |
| `tcalvl_capture` | Training | PHY | DFI clocks after calibration command on `dfi_cs` before `dfi_calvl_capture` pulse. |
| `tcalvl_cc` | Training | PHY | Min DFI clocks from one calibration command to the next. |
| `tcalvl_cs_ca` | Training | PHY | PHY DFI clocks from `dfi_calvl_ca_sel` assertion to `dfi_cs`. |
| `tcalvl_data` | Training | System | Min DFI PHY clocks `dfi_calvl_data` must be held for DRAM hold time. |
| `tcalvl_en` | Training | PHY | Min DFI clocks from `dfi_calvl_en` assertion to `dfi_cke` de-assertion. |
| `tcalvl_max` | Training | MC | Max DFI clocks MC waits for `dfi_calvl_resp` after asserting `dfi_calvl_en`. |
| `tcalvl_resp` | Training | MC | Max DFI clocks from `dfi_calvl_req` to MC asserting `dfi_calvl_en`. |
| `tcalvl_strobe` | Training | System | Min DFI PHY clocks from `dfi_calvl_data` to `dfi_calvl_strobe` for DRAM setup time. |
| `trdlvl_en` | Training | PHY | Min DFI clocks from `dfi_rdlvl_en`/`dfi_rdlvl_gate_en` assertion to first read/MRR command. |
| `trdlvl_max` | Training | MC | Max DFI clocks MC waits for `dfi_rdlvl_resp` after setting read training enable. |
| `trdlvl_resp` | Training | MC | Max DFI clocks from read training request to MC asserting corresponding enable. |
| `trdlvl_rr` | Training | PHY | Min DFI clocks between consecutive read-training read commands. |
| `twdqlvl_en` | Training | PHY | Min DFI clocks from any `dfi_wdqlvl_en` assertion to first write command. |
| `twdqlvl_max` | Training | MC | Max DFI clocks MC waits for `dfi_wdqlvl_resp` after asserting `dfi_wdqlvl_en`. |
| `twdqlvl_resp` | Training | MC | Max DFI clocks from `dfi_wdqlvl_req` to MC asserting `dfi_wdqlvl_en`. |
| `twdqlvl_rw` | Training | PHY | Min DFI clocks from last read in calibration sequence to first write of next set. |
| `twdqlvl_ww` | Training | PHY | Min DFI clocks inserted between write commands during write DQ training. |
| `twrlvl_en` | Training | PHY | Min DFI clocks from `dfi_wrlvl_en` assertion to first `dfi_wrlvl_strobe` assertion. |
| `twrlvl_max` | Training | MC | Max DFI clocks MC waits for `dfi_wrlvl_resp` after setting `dfi_wrlvl_en`. |
| `twrlvl_resp` | Training | MC | Max DFI clocks from `dfi_wrlvl_req` to MC asserting `dfi_wrlvl_en`. |
| `twrlvl_ww` | Training | PHY | Min DFI clocks from one `dfi_wrlvl_strobe` assertion to the next. |
| `tlp_resp` | Low Power | MC | Max DFI clocks from low-power request assertion to `dfi_lp_ack` assertion (min 1, max 7). |
| `tlp_wakeup` | Low Power | MC | Target max DFI clocks that `dfi_lp_ack` may stay asserted after request de-asserts (min 16). |
| `tphy_db_train_en` | DB Training | PHY | PHY DFI clocks after `dfi_db_train_en` asserts until first training command can be issued. |
| `tphy_db_train_resp` | DB Training | PHY | Max DFI clocks from PHY DQ input to `dfi_db_train_resp` output. |
| `tphymstr_resp` | PHY Master | MC | Max DFI clocks from `dfi_phymstr_req` assertion to `dfi_phymstr_ack` assertion. |
| `tphymstr_rfsh` | PHY Master | PHY | Max DFI clocks PHY needs to forward a refresh command from MC to DRAM while master. |
| `tphymstr_type0` | PHY Master | PHY | Max DFI clocks `dfi_phymstr_req` may stay asserted after ack for type 0. |
| `tphymstr_type1` | PHY Master | PHY | Max for type 1. |
| `tphymstr_type2` | PHY Master | PHY | Max for type 2. |
| `tphymstr_type3` | PHY Master | PHY | Max for type 3. |
| `tcalvl_disconnect` | Disconnect | PHY | Max clocks to disconnect CA training with `dfi_disconnect_error=0`. |
| `tcalvl_disconnect_error` | Disconnect | PHY | Same with `dfi_disconnect_error=1`. |
| `tctrlupd_disconnect` | Disconnect | PHY | Max clocks to disconnect a control update. |
| `tctrlupd_disconnect_error` | Disconnect | PHY | Same with error disconnect. |
| `tphyupd_disconnect` | Disconnect | PHY | Max clocks to disconnect a PHY update. |
| `tphyupd_disconnect_error` | Disconnect | PHY | Same with error disconnect. |
| `tphymstr_disconnect` | Disconnect | PHY | Max clocks to disconnect a PHY master request. |
| `tphymstr_disconnect_error` | Disconnect | PHY | Same with error disconnect. |
| `trdlvl_disconnect` | Disconnect | PHY | Max clocks to disconnect read data eye training. |
| `trdlvl_disconnect_error` | Disconnect | PHY | Same with error disconnect. |
| `trdlvl_gate_disconnect` | Disconnect | PHY | Max clocks to disconnect gate training. |
| `trdlvl_gate_disconnect_error` | Disconnect | PHY | Same with error disconnect. |
| `twdqlvl_disconnect` | Disconnect | PHY | Max clocks to disconnect write DQ training. |
| `twdqlvl_disconnect_error` | Disconnect | PHY | Same with error disconnect. |
| `twrlvl_disconnect` | Disconnect | PHY | Max clocks to disconnect write leveling. |
| `twrlvl_disconnect_error` | Disconnect | PHY | Same with error disconnect. |
| `tgeardown_delay` | Geardown | PHY | Delay from `dfi_geardown_en` assertion until PHY is ready to receive commands. |

## Programmable parameters

| Parameter | Sub-interface | Defined by | Description |
| --- | --- | --- | --- |
| `phycrc_mode` | Write Data | PHY | `0` = CRC in MC; `1` = CRC in PHY. |
| `phydbi_mode` | Write/Read Data | PHY | `0` = DBI in MC; `1` = DBI in PHY. |
| `dfidata_bit_enable` | Status | MC/PHY | Valid data bits on `dfi_wrdata` and `dfi_rddata`. |
| `phyfreq_range` | Status | PHY | Number of `dfi_frequency` values supported (1-32). |
| `mcrdlvl_slice_group` | Training | MC | Per-slice grouping of `dfi_rdlvl_en` bits. |
| `phyrdlvl_slice_group` | Training | PHY | PHY-side counterpart of `mcrdlvl_slice_group`. |
| `phycalvl_en` | Training | PHY | `1` = DFI CA training enabled. |
| `phyrdlvl_en` | Training | PHY | PHY supports read data eye training. |
| `phyrdlvl_gate_en` | Training | PHY | PHY supports gate training. |
| `phywdqlvl_bst` | Training | PHY | Consecutive write bursts per write DQ training sequence. |
| `phywrlvl_en` | Training | PHY | PHY supports write leveling. |
| `syswrlvl_strobe_num` | Training | MC | Minimum clocks `dfi_wrlvl_strobe` asserts per request. |
| `syscs_state` | PHY Master | MC/PHY | Per-CS active/inactive state. |
| `phychannel_en` | LPDDR4 Channels | System/PHY | Enabled channels in LPDDR4 combined mode. |
