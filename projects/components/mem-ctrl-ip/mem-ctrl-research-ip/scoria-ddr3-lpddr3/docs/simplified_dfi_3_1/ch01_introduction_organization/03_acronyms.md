# Acronyms

| Term | Meaning |
| --- | --- |
| ACT | DRAM Activate command |
| BL | Burst length |
| CA | Command/Address bus (LPDDR3/LPDDR2) |
| CRC | Cyclic redundancy check |
| DBI | Data bus inversion |
| DFI | DDR PHY Interface |
| DFI PHY clock | PHY-side clock, equal to DRAM clock frequency |
| DRAM | Dynamic random-access memory |
| DQS | Data strobe |
| MC | Memory controller |
| MPR | Multi-purpose register (DRAM training mode) |
| MRR | Mode register read (LPDDR3/LPDDR2) |
| MRW | Mode register write |
| NOP | No operation command |
| ODT | On-die termination |
| PHY | Physical layer that drives DRAM pins |
| PRE | DRAM Precharge command |
| RD | DRAM Read command |
| REF | DRAM Refresh command |
| UI | Unit interval (half a data word) |
| WR | DRAM Write command |

: Acronyms used in this book

| DFI signal group | Meaning |
| --- | --- |
| `_pN` | Phase N of a frequency-ratio signal, MC to PHY |
| `_wN` | DFI data word N, PHY to MC in frequency-ratio systems |
| `_aN` | PHY clock cycle N for variable-pulse-width signals |

: Suffix notation

**Source:** DFI Specification v3.1 section 6.0, Glossary
