# Write Data and Read Data Interfaces

The write data interface moves write data and mask/DBI from MC to PHY. The read data interface
returns read data, data valid, and read DBI from PHY to MC. Both interfaces are phase- or word-
replicated in frequency-ratio systems.

## Write data signals

| Signal | Width | Default | Direction | What it does |
| --- | --- | --- | --- | --- |
| `dfi_wrdata` | DFI Data Width | - | MC -> PHY | Write data bus. Data appears `tphy_wrdata` cycles after `dfi_wrdata_en` asserts. Carries MC-generated CRC word when `phycrc_mode = 0`. |
| `dfi_wrdata_cs` | DFI Physical Rank Width | - | MC -> PHY | Write data-path chip select (polarity of `dfi_cs`). Selects target rank for write data or, during write leveling, the rank being trained. New in 4.0. |
| `dfi_wrdata_en` | DFI Data Enable Width | 0x0 | MC -> PHY | Write data/mask enable. Ideally one bit per PHY data slice; all bits identical so widths may differ. |
| `dfi_wrdata_mask` | DFI Data Width / 8 | - | MC -> PHY | Byte mask or write DBI. Same timing as `dfi_wrdata`. Bit N masks `dfi_wrdata[8N+7:8N]`. When DBI is enabled and `phydbi_mode = 0`, this bus carries write DBI instead of mask. |

: DFI 4.0 write data signals

### Write DBI and write CRC

Write DBI reuses `dfi_wrdata_mask`. There is no separate `dfi_wrdata_dbi` signal in DFI 4.0. If
the PHY handles DBI (`phydbi_mode = 1`) the MC presents plain data and mask; if the MC handles
DBI (`phydbi_mode = 0`) the mask bus is repurposed to carry the DBI pattern.

Write CRC may be generated by the MC (`phycrc_mode = 0`) or by the PHY (`phycrc_mode = 1`).
When the MC generates CRC, the CRC word is appended on `dfi_wrdata` after the data burst.

## Read data signals

| Signal | Width | Default | Direction | What it does |
| --- | --- | --- | --- | --- |
| `dfi_rddata` | DFI Data Width | - | PHY -> MC | Read data bus. Valid within `tphy_rdlat` cycles after `dfi_rddata_en` asserts. Word-suffixed `_wN`. |
| `dfi_rddata_cs` | DFI Physical Rank Width | inactive | MC -> PHY | Read data-path chip select (polarity of `dfi_cs`). Selects target rank for read data or, during read training, the rank being trained. New in 4.0. |
| `dfi_rddata_dbi` | DFI DBI Width | - | PHY -> MC | Read DBI. Sent with `dfi_rddata`; valid only when `phydbi_mode = 0`. Word-suffixed `_wN`. |
| `dfi_rddata_dnv` | DFI Data Width / 8 | 0x0 | PHY -> MC | Data-not-valid per byte (LPDDR2). Same timing as `dfi_rddata_valid`. Word-suffixed `_wN`. |
| `dfi_rddata_en` | DFI Data Enable Width | 0x0 | MC -> PHY | Read data enable. Asserted `trddata_en` cycles after read command and held for expected contiguous read data. |
| `dfi_rddata_valid` | DFI Read Data Valid Width | 0x0 | PHY -> MC | Per-slice read data valid. One-to-one response to `dfi_rddata_en` within `tphy_rdlat`. Word-suffixed `_wN`. |

: DFI 4.0 read data signals

### Read DBI

Read DBI has a dedicated `dfi_rddata_dbi` bus. The PHY returns it alongside `dfi_rddata` when
DBI is enabled and `phydbi_mode = 0`. If `phydbi_mode = 1` the PHY inverts data internally and
the `dfi_rddata_dbi` signal is not used.

## Programmable parameters for data path

| Parameter | Defined by | Description |
| --- | --- | --- |
| `phycrc_mode` | PHY | `0` = CRC generation/validation in MC; `1` = in PHY. |
| `phydbi_mode` | PHY | `0` = DBI generation and data inversion in MC; `1` = in PHY. |
| `dfidata_bit_enable` | MC/PHY | Defines valid data bits on `dfi_wrdata` and `dfi_rddata`. Replaces the removed `dfi_data_byte_disable` signal. |

: Data-path programmable parameters

## Key data-path timing parameters

| Parameter | Defined by | Description |
| --- | --- | --- |
| `tphy_wrlat` | PHY | DFI PHY clocks from write command to `dfi_wrdata_en` assertion. |
| `tphy_wrdata` | PHY | DFI PHY clocks from `dfi_wrdata_en` assertion to write data driven on `dfi_wrdata`. |
| `twrdata_delay` | System | DFI clocks from `dfi_wrdata_en` assertion to write data transfer completion on DRAM bus. |
| `trddata_en` | System | DFI PHY clocks from read command to `dfi_rddata_en` assertion. |
| `tphy_rdlat` | PHY | Max DFI PHY clocks from `dfi_rddata_en` assertion to each corresponding `dfi_rddata_valid` bit. |
| `tphy_rdcslat` | PHY | DFI PHY clocks from read command to assertion of associated `dfi_rddata_cs`. |
| `tphy_rdcsgap` | PHY | Min additional DFI PHY clocks between commands when changing target rank on `dfi_rddata_cs`. |
| `tphy_wrcslat` | PHY | DFI PHY clocks from write command to assertion of associated `dfi_wrdata_cs`. |
| `tphy_wrcsgap` | PHY | Min additional DFI PHY clocks between commands when changing target rank on `dfi_wrdata_cs`. |
| `tphy_crcmax_lat` | System | Max DFI PHY clocks from `dfi_wrdata_en` (CRC word cycle) to associated CRC error on `dfi_alert_n`. |
| `tphy_crcmin_lat` | System | Min DFI PHY clocks for the same path. |

: Data-path timing parameters

**Source:** DFI Specification v4.0 sections 3.2, 3.3, 4.4, 4.5, 4.6, Tables 7-12
