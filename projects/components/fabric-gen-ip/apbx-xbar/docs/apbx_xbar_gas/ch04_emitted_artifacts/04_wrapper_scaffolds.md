# Wrapper Scaffolds

The generator emits only the core crossbar module. Wrapper scaffolds for testbench convenience exist only for the four legacy fixtures and are **not** regenerated by `generate_xbars.py`. If a new variant needs a wrapper, create it by hand in the DV area or add a wrapper emission stage to the generator.

## Filelist convention

Area flows that consume the generated modules typically reference the RTL directly rather than a generated `.f` file. An example filelist for the standard variants would contain:

```
rtl/amba/apb4/xbar/apbx_xbar_2to4.sv
rtl/common/arbiter_round_robin.sv
rtl/common/apb4_slave.sv
rtl/common/apb4_master.sv
```

The exact dependencies are determined by the variant (APB5 ports add `apb5_slave.sv` and `apb5_master.sv`). The component-level `Makefile` or area regression flow maintains the canonical filelist.
