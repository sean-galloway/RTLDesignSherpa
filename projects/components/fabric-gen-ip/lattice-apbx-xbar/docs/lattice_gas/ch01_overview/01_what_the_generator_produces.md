# What the Generator Produces

The Lattice generator (`bin/apbx_xbar_generator.py`) emits a single-file SystemVerilog module for an M×N APB crossbar. The module is parameterized at elaboration time for address width, data width, and base address; the master/slave counts and address-map stride are fixed at generation time.

## Output artifacts

| Artifact | Description |
|----------|-------------|
| `apbx_xbar_<M>to<N>.sv` | Core crossbar module. |
| `apbx_xbar_<M>to<N>_wrap.sv` | Testbench scaffold (only for the four legacy fixtures). |
| `apbx_xbar_<M>to<N>.f` | Filelist (when generated by an area flow, not by the generator itself). |

The generator emits the final form: banner, SPDX header, `reset_defs.svh` include, module header, and complete internal logic. No post-processing is required.

## Architecture in the generated module

The generated module contains:

1. **Master-side APB slave modules** — `apb4_slave` or `apb5_slave` per master, converting APB → cmd/rsp.
2. **cmd/rsp fabric** — address decode, per-slave round-robin arbitration, response routing.
3. **Slave-side APB master modules** — `apb4_master` or `apb5_master` per slave, converting cmd/rsp → APB.

The generator also supports mixed APB4/APB5 ports and optional APB5 parity.
