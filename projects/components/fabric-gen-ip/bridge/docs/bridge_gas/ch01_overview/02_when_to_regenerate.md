# When to Regenerate

Any change to the generator or its inputs can change every emitted file. Bridge enforces a **full regeneration discipline**.

## Triggers for Full Regeneration

Regenerate every generated bridge in `rtl/generated/` when any of the following change:

- `bin/bridge_generator.py`
- Any Python file under `bin/bridge_pkg/`
- Any Jinja template under `bin/bridge_pkg/jinja_templates/`
- Any shared converter or wrapper IP the filelist pulls in, if its interface changes

Do **not** regenerate a single bridge and leave the rest untouched. Generated files share package definitions, converter selection logic, and filelist conventions; partial regeneration creates version skew.

## Regeneration Workflow

```bash
cd projects/components/fabric-gen-ip/bridge/bin
make clean          # removes rtl/generated/
make all            # regenerates every bridge in bridge_batch.csv
```

After regenerating RTL, also regenerate tests if the generator's test templates changed:

```bash
python bridge_generator.py --bulk bridge_batch.csv --generate-tests
```

Then run the DV suite from a clean build directory:

```bash
cd ../dv/tests
make clean-all && make run-all-func
```

## When Inputs (Not Code) Change

If only the TOML or CSV for one bridge changes, regenerate that bridge alone is safe only when **no generator code changed**:

```bash
python bridge_generator.py --ports test_configs/my_bridge.toml
```

If in doubt, run `make clean && make all`.

## Identifying Generated Files

Each generator class stamps its own header. Grepping for the generator name is more reliable than grepping for `bridge_generator.py`:

| Generator class | Header string |
|-----------------|---------------|
| `BridgeModuleGenerator` | `Generated by: BridgeModuleGenerator` |
| `PackageGenerator` | `Generated by: PackageGenerator` |
| `CrossbarGenerator` | `Generated by: CrossbarGenerator` |
| `AdapterGenerator` | `Generated by: AdapterGenerator` |
| `SlaveAdapterGenerator` | `Generated by: SlaveAdapterGenerator` |

Hand-written files in `rtl/` (for example `bridge_cam.sv`) are never regenerated and must not be deleted by `make clean`.
