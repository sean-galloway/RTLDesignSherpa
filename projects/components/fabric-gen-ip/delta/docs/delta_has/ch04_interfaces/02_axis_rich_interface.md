# AXI-Stream Rich Interface (TSTRB + AMBA5)

## Rich Master Interface (S_AXIS)

When `--strb-width N` and/or `--amba5` are used, the master interface adds the following signals in addition to the base set. The check signals are IHI 0051B chapter 5 (`Check_Type = Odd_Parity_Byte_All`). Names and widths match `rtl/amba/axis5/*`.

| Signal | Width | Direction | Presence | Description |
|--------|-------|-----------|----------|-------------|
| `s_axis_tstrb[m]` | `STRB_WIDTH` | Input | `--strb-width N` | Byte qualifier / strobe. Pass-through to `m_axis_tstrb`. |
| `s_axis_twakeup[m]` | 1 | Input | `--amba5` | Wakeup hint. May assert before `TVALID`. |
| `s_axis_tdatachk[m]` | `TDATACHK_W` = `DATA_WIDTH/8` | Input | `--amba5` | Odd parity per `TDATA` byte. Checked, then carried. |
| `s_axis_tstrbchk[m]` | `TSTRBCHK_W` = `ceil(STRB_WIDTH/8)` | Input | `--amba5` and `--strb-width N` | Odd parity over `TSTRB`. Checked, then carried. |
| `s_axis_tlastchk[m]` | 1 | Input | `--amba5` | `~TLAST`. Checked, then carried. |
| `s_axis_tidchk[m]` | `TIDCHK_W` = `ceil(ID_WIDTH/8)` | Input | `--amba5` | Odd parity over `TID`. Checked, then carried. |
| `s_axis_tdestchk[m]` | `TDESTCHK_W` = `ceil(DEST_WIDTH/8)` | Input | `--amba5` | Odd parity over `TDEST`. Checked, then carried. |
| `s_axis_tuserchk[m]` | `TUSERCHK_W` = `ceil(USER_WIDTH/8)` | Input | `--amba5` | Odd parity over `TUSER`. Checked, then carried. |
| `s_axis_tvalidchk[m]` | 1 | Input | `--amba5` | `~TVALID`. Checked every cycle out of reset. |
| `s_axis_treadychk[m]` | 1 | Output | `--amba5` | `~TREADY`, generated by the crossbar. |
| `s_axis_twakeupchk[m]` | 1 | Input | `--amba5` | `~TWAKEUP`. Checked every cycle out of reset. |
| `s_parity_error[m]` | 1 | Output | `--amba5` | Sticky. Set by any check failure on master port `m`. Cleared by `aresetn`. |

## Rich Slave Interface (M_AXIS)

| Signal | Width | Direction | Presence | Description |
|--------|-------|-----------|----------|-------------|
| `m_axis_tstrb[s]` | `STRB_WIDTH` | Output | `--strb-width N` | Byte qualifier from the granted master. |
| `m_axis_twakeup[s]` | 1 | Output | `--amba5` | Wakeup hint. OR of all masters whose `TDEST` selects slave `s`. |
| `m_axis_tdatachk[s]`, `m_axis_tstrbchk[s]`, `m_axis_tlastchk[s]`, `m_axis_tidchk[s]`, `m_axis_tdestchk[s]`, `m_axis_tuserchk[s]` | as on the master side | Output | `--amba5` (`tstrbchk` also needs `--strb-width N`) | Payload check bits of the granted master, carried unchanged. All ones while no master is granted. |
| `m_axis_tvalidchk[s]` | 1 | Output | `--amba5` | `~TVALID`, generated by the crossbar. |
| `m_axis_treadychk[s]` | 1 | Input | `--amba5` | `~TREADY`. Checked every cycle out of reset. |
| `m_axis_twakeupchk[s]` | 1 | Output | `--amba5` | `~TWAKEUP`, generated by the crossbar. |
| `m_parity_error[s]` | 1 | Output | `--amba5` | Sticky. Set by a bad `TREADYCHK` on slave port `s`. Cleared by `aresetn`. |

## TSTRB Semantics

- `TSTRB` is treated as an opaque byte-qualifier sideband.
- The crossbar forwards the granted master's `TSTRB` to the selected slave.
- Delta does not gate `TVALID` based on `TSTRB` or modify strobe bits.

## TWAKEUP Semantics

`TWAKEUP` is an AMBA 5 hint, not a handshake signal:

- A master may assert `s_axis_twakeup[m]` before `s_axis_tvalid[m]` to wake the target slave.
- The crossbar decodes `s_axis_tdest[m]` and ORs the hint to the indicated slave.
- `m_axis_twakeup[s]` may be high while `m_axis_tvalid[s]` is low.
- No grant is required for `TWAKEUP` steering.

## Check-Signal Semantics (IHI 0051B Chapter 5)

- Parity is odd. A check bit and the bits it covers hold an odd number of ones. Bit `[n]` covers bits `[8n+7:8n]`, and the top bit covers a short remainder (section 5.3).
- Payload checks (`TDATACHK` through `TUSERCHK`) are checked only while `TVALID` is high. `TVALIDCHK`, `TREADYCHK` and `TWAKEUPCHK` are checked on every cycle out of reset.
- Payload check bits are carried end to end with the beat, never regenerated. A bad bit at a master port stays bad at the slave port.
- A failed check sets the port's sticky error flag. It does not stall, drop or alter the beat.
- Every check bit is computed or checked by a `rtl/common/dataint_parity` instance. The compile closure of a generated `--amba5` crossbar includes `rtl/common/filelists/dataint_parity.f`.

## Parameter Implications

| Option | Generated Parameter | Port Effect |
|--------|---------------------|-------------|
| `--strb-width N` | `STRB_WIDTH = N` | Adds `s_axis_tstrb` and `m_axis_tstrb` arrays. |
| `--amba5` | `TDATACHK_W`, `TIDCHK_W`, `TDESTCHK_W`, `TUSERCHK_W` (plus `TSTRBCHK_W` with `--strb-width`), each derived from its payload width | Adds `TWAKEUP`, the nine check signals and the two `*_parity_error` arrays. Requires a whole-byte `--data-width`. |
