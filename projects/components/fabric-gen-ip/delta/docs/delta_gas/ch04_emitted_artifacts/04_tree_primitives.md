# Tree Primitives

Delta includes scaffolding for tree topologies in addition to the flat crossbar. These primitives are generated separately and are intended for future hierarchical switches.

## `delta_split_1to2`

Generated by `delta_generator.py --nodes`. It routes one AXI-Stream input to two outputs based on a configurable `TDEST` bit:

```systemverilog
assign route_to_1 = s_axis_tdest[SPLIT_BIT];
assign m0_axis_tvalid = s_axis_tvalid && !route_to_1;
assign m1_axis_tvalid = s_axis_tvalid && route_to_1;
assign s_axis_tready  = route_to_1 ? m1_axis_tready : m0_axis_tready;
```

## `delta_merge_2to1`

Generated by `complete_tree_generator.py --type merger`. It arbitrates two inputs to one output using round-robin with packet atomicity.

## Fan-out / fan-in trees

`complete_tree_generator.py --type fanout --size N` and `--type fanin --size N` emit structural scaffolds for cascaded splitters and mergers. The implementations are currently partial; they illustrate the intended topology and are not yet part of the regression baseline.

## Filelist convention

A complete Delta subsystem typically needs only:

```
rtl/delta_axis_flat_<M>x<N>.sv
```

Tree-based systems add the appropriate splitter/merger files. The component-level `Makefile` or area flow maintains the canonical filelist.
