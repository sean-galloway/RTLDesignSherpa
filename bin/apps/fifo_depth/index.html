Notes

  • Items read during the write burst uses floor, the conservative direction: fewer reads counted means a larger depth.
  • Sync margin: the full flag lags real fill by N_FLOP_CROSS write clocks. This sheet uses a 1x margin (some sources use 2x).
  • Encoding is chosen by the USE_JOHNSON parameter on both fifo_async (rtl/common) and gaxi_fifo_async (rtl/amba/gaxi): USE_JOHNSON=0 (default) uses Gray pointers and DEPTH must be a power of 2; USE_JOHNSON=1 uses Johnson pointers and DEPTH must be even. An illegal combination fails at elaboration, not silently.
  • Idle cycles: N idle cycles means each transfer takes (1+N) clocks. 100% duty = 0 idle, 50% duty = 1 idle, 25% duty = 3 idle.
  • Steady state: if the average write rate exceeds the average read rate, no depth is enough — back-pressure is required.
  • First-word latency: the sheet assumes the reader starts in the same cycle as the first write. Add 1 if the FIFO starts empty and reads must wait for the first item to land.
  • Clock drift is deliberately not modeled: real crystal tolerance is ppm-level. To size a worst case, enter the worst-case numbers directly (fastest fA, slowest fB).
