Notes

  • Word-addressed cache: each address is a 32-bit word address.
  • Address split: block offset = log2(block size) low bits; set index = next log2(sets) bits; tag = the remainder.
  • Miss classes: compulsory = first touch of a block; capacity = would miss even in a fully-associative cache of the same total size; conflict = caused by set contention.
  • The shadow fully-associative cache uses the same replacement policy and, for RANDOM, the same seed on an independent RNG stream.
