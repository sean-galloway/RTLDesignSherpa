Notes

  • Skew is signed: positive means launch edge is later than capture edge (steals setup margin, helps hold). Negative means launch is earlier (helps setup, hurts hold).
  • Setup slack = T - tCO - tLOGIC - tROUTE + skew - tSU.
  • Hold slack = tCO + tLOGIC + tROUTE - skew - tHD.
  • Hold violations are fixed by adding delay, not removing it. Adding a buffer or constraining a minimum delay increases the path so it remains stable through the capture window.
  • The pipeline panel assumes ideal balanced stages and ignores skew. Per-stage logic = (tLOGIC + tROUTE) / K, so min period = tCO + per-stage logic + tSU.
  • Throughput rises with K, but latency also rises. There is a floor from tCO + tSU even with infinite pipelining.
