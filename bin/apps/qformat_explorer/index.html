Notes

  • Signed Qm.n means 1 sign bit + m integer bits + n fractional bits, for a total width of m + n + 1 bits. Unsigned Qm.n means m integer bits + n fractional bits, for a total width of m + n bits.
  • Round-to-nearest is used when encoding a real value. Values exactly halfway round away from zero (JavaScript Math.round).
  • Signed wrap mode performs true two's-complement wraparound: overflowed values modulo 2^(m+n+1). Unsigned wrap mode wraps modulo 2^(m+n).
  • Multiply growth: Qm.n * Qm.n -> Q(2m).(2n), then the result is rescaled back to the original Qm.n format.
  • Hardware reality is the "double-quantized" row: operands are first quantized to the fixed grid, the operation runs, and the final result is quantized again.
  • Click any bit in the rendered bit pattern to toggle it; the real value and hex field update immediately.
