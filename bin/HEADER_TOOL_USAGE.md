# add_file_headers.py

Usage, flags and worked examples: `python3 bin/add_file_headers.py --help`.
The tool's own help already carries all of it, including the dry-run and
per-directory examples.

285 lines restating that help used to live here. A tool's usage belongs in its
`--help`, where it is generated from the argument parser and cannot disagree
with the code; a prose copy beside it can only fall behind.
